# Advisory vs blocking review (2026-11-27)

Every message the backend raises (1,004 sites) was read against the code around it and the 2025 IRS instructions by six review
agents; every proposed change was then re-checked against the code. The test: *if the user ignores this message and files, is the
return wrong?* No - advisory. Probably, but the user may know better - blocking (compute anyway allowed). Certainly (a figure the
app knows is wrong or skipped, a required answer missing, answers that conflict) - can't be overridden.

**128 proposed, 116 recommended, 12 rejected on re-check.** Nothing is lowered to advisory.

| From | To | Recommended |
|---|---|---|
| Advisory | Blocking | 54 |
| Advisory | Can't override | 7 |
| Blocking | Can't override | 52 |
| Can't override | Blocking | 3 |

Each message that becomes "can't override" must name the screen that fixes it (NonOverrideableFlagMessagesTest); a few need
their wording changed for that.
