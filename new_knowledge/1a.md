# Form 1040 line 1a — how the app does it

IRS rules: `C:\us-tax\new_lines\1a.md`. Flowchart: `C:\us-tax\new_flowcharts\1a.md`.
Paths are relative to `C:\us-tax`. `TRCS` = `us-tax-be/src/main/java/com/ustax/microservices/TaxReturnComputeService.java`.

---

## 1. Status

Line 1a is computed. The app sums W-2 box 1 from the household's `w-2` statements, drops statutory-employee W-2s
(with a non-blocking Schedule C advisory), subtracts W-2 box 11 per W-2, adds Form 4852 line 7a (W-2 substitutes),
and subtracts the inmate wages picked on the Employment form. On married-filing-separately and dependent's-own
returns only the filer's W-2s (box a) count. Blocking flags cover a missing W-2, inmate wages larger than all wage
sources, a W-2 without box a on an MFS return, and a "missing W-2" answer with no Form 4852.

**9 differences from the IRS rules** (D-1a-1 … D-1a-9). The most serious: a dependent's W-2 entered on the
dependent's tab is added to the parent's line 1a on a single / joint / head-of-household return (D-1a-1), and
Guam / Virgin Islands / American Samoa W-2s are never read (D-1a-3). Both produce a wrong amount with no flag.

## 4. How it is computed

Methods:

- Load: `TRCS:3105-3108` — `statementDataService.listEntriesWithData(uid, "w-2")`, passed through
  `CommunityProperty.withCommunityPropertySplit` (`us-tax-be/.../microservices/CommunityProperty.java:35-107`).
- W-2 side: `computeLine1aWages` `TRCS:40957-41027`.
- Assembly: `buildIncome` `TRCS:18226`, line 1a block `TRCS:18256-18357`, rounding `TRCS:18435`, output
  `TRCS:18575-18580`.
- Form 4852: `extractForm4852Line1aWages` `TRCS:46799-46816`.
- Return scoping: `prepare(long)` `TRCS:374-395`; `loadPersonalForms` `TRCS:728-737` (primary MFS stamp);
  `us-tax-be/.../multireturn/MfsFormScoper.java:780-791` (`stampPrimaryMfs`), `:850-857` (MFS legs);
  `us-tax-be/.../multireturn/DependentOwnFormScoper.java:170-177` (dependent's own return).

Steps, mirroring `new_lines/1a.md` section 6:

1. **Collect the W-2s that belong on this return.** The app loads every W-2 stored under the account for the year —
   taxpayer's, spouse's and dependents' (`W2Mapper.java:85-96`). It then filters inside `computeLine1aWages`:
   - If `filing-status.scopedFilerSsn` is set, only W-2s whose `employeeSSN` equals it are kept; a W-2 with no box a
     is dropped (`TRCS:40978-40982`). The key is set on the MFS legs (`MfsFormScoper.java:855-857`), on a primary
     MFS return (`MfsFormScoper.java:790`, called from `TRCS:733-736`) and on a dependent's own return
     (`DependentOwnFormScoper.java:175-177`).
   - On MFS, a W-2 whose box a equals the other spouse's SSN (`spouse.ssn`, else `filing-status.mfsOtherSpouseSsn`) is
     dropped (`TRCS:18285-18291`, `TRCS:40989-40993`).
   - On single, joint, head-of-household and qualifying-surviving-spouse returns **no filter runs**: every W-2 in the
     account counts, including a dependent's (D-1a-1).
   - MFS with community property answered Yes: before any of this, each spouse's box 1 (and box 2) is split — the
     filer's W-2 keeps `box1 × (1 − p/2)`, and a copy carrying `box1 × p/2` of the other spouse's W-2 is added under
     the filer's SSN (`CommunityProperty.java:58-96`; `p` = `cpWagesCommunityPct`, default 100). Box 11 is not split.
2. **Statutory employee.** A W-2 with `statutoryEmployee == true` is skipped and the non-blocking advisory
   `STATUTORY_EMPLOYEE_W2_SCHEDULE_C` is added (`TRCS:40997-41009`). The amount is **not** carried to Schedule C; the
   user must add a business marked `statutoryEmployeeW2Link` and type the box 1 amount (`TRCS:27034`). Nothing checks
   that they did (D-1a-4).
3. **Missing / incorrect W-2 → Form 4852.** After the W-2 sum, the taxpayer's Form 4852 line 7a total is added, and
   the spouse's unless the return is MFS (`TRCS:18322`). Only entries whose substitute type is `w2` count; a blank
   type is treated as `w2` unless any line 8 (1099-R) field is filled (`TRCS:46804-46811`). The W-2 the Form 4852
   replaces is **not** removed (D-1a-6); a corrected W-2c is expected to be typed over the original W-2, with
   `DUPLICATE_W2_EMPLOYER_EIN` (advisory) when two W-2s share an EIN (`TRCS:14006-14037`).
4. **Add box 1.** `wagesTipsOtherCompAmount` of each kept W-2; a W-2 with no box 1 is skipped (`TRCS:41010-41013`).
   Amounts keep cents.
5. **Subtract inmate wages.** `inmateWagesAmount` of the taxpayer **plus the spouse** Employment forms
   (`TRCS:18327-18329`) is subtracted from the total, floored at 0 (`TRCS:18355-18357`). The spouse amount is
   subtracted even on an MFS return, while Schedule 1 line 8u leaves it out on MFS (`TRCS:32045`) (D-1a-5). If the
   inmate amount is larger than the wage total, the blocking flag `INMATE_WAGES_EXCEEDS_WAGE_SOURCES` is raised first
   (`TRCS:18342-18354`).
6. **Subtract NQDC / §457 pension.** (In code order this happens inside the W-2 loop, before the Form 4852 and inmate
   steps.) Per W-2, `nonqualifiedPlansAmount` (box 11) is subtracted from that W-2's box 1, floored at 0
   (`TRCS:41016-41019`). Box 11 is treated as always being part of box 1 and as always being a
   distribution (D-1a-2). Schedule 1 line 8t adds back every non-statutory W-2's box 11 with **no person filter**
   (`sumW2Box11Nqdc`, `TRCS:41207-41219`, used at `TRCS:32498-32499`) (D-1a-9).
7. **Round.** `roundMoney` (half-up to whole dollars) on the total (`TRCS:18435`) — cents are summed first.
8. **Output.** If the result is not null it is stored on `Income.wages`; if it is null (no W-2s, no Form 4852) and
   either spouse answered Yes to "Did you receive any wages", `0` is stored; otherwise it stays null
   (`TRCS:18576-18580`).

Not modelled anywhere on this path: chapter 11 bankruptcy allocation (D-1a-7) and registered-domestic-partner
community income (D-1a-8). The foreign earned income exclusion and nontaxable Medicaid waiver payments do not touch
line 1a (handled on Schedule 1 lines 8d / 8s), which matches the IRS.

## 9. Limits and out of scope

- **Form W-2c and Form 1040-X**: a W-2c is entered by typing the corrected figures over the original W-2; an amended
  return is not produced.
- **Forms W-2PR / 499R-2 and W-2CM** are not in the statement catalog.
- **Bona fide residents of a territory** (exclusion under §931 / §933) are handled by the possession-residence
  exclusion form, not by line 1a.
- **Inmate amount** is trusted as saved; the backend does not re-derive it from the picked W-2 ids.
- Deliberate design: line 1a is a three-state value — null (no wages concept), 0 (wages answered Yes, nothing
  computed), positive (`TRCS:18576-18580`; `knowledge/canonical-null-zero-semantic.md`).
