# Form 1040 line 2a — how the app does it

IRS rules: `C:\us-tax\new_lines\2a.md`. Flowchart: `C:\us-tax\new_flowcharts\2a.md`. Taxable interest (line 2b),
computed by the same methods: `C:\us-tax\new_knowledge\2b.md`.
Paths are relative to `C:\us-tax`. `TRCS` = `us-tax-be/src/main/java/com/ustax/microservices/TaxReturnComputeService.java`.

---

## 1. Status

Line 2a is computed, together with line 2b, by `computeInterestIncome` / `computeInterestForPerson`. It adds
Form 1099-INT box 8 less box 13 per statement (box 9 is not added), Form 1099-OID box 11, Form 1099-DIV box 12, the
tax-exempt part of Form 1099-OID box 2 that the user enters, hand-entered tax-exempt interest, and the Form 8814
line 1b totals of the children the parent elects to report, less a hand-entered tax-exempt premium. Statements are
assigned to the taxpayer or spouse by their recipient TIN; a statement whose TIN is a dependent's is correctly left
off the parent's return. Line 2a is not added to line 9; it feeds the Social Security Benefits Worksheet, the premium
tax credit MAGI and other add-backs.

**4 differences from the IRS rules** (D-2a-1 … D-2a-4), plus one unverified item. The most serious: Schedule K-1
tax-exempt interest (Form 1065 box 18 code A, Form 1120-S box 16 code A) is stored but never read (D-2a-1), and a
statement with a blank recipient TIN is counted as "the taxpayer's" on every return — so on both MFS returns and on
every dependent's own return (D-2a-3, same root cause as D-1a-1). Both are silent.

**D-1a-1 check (a dependent's statement on the parent's return):** for 1099-INT / 1099-OID / 1099-DIV the repeat does
**not** occur when the statement carries the dependent's SSN — `belongsToPerson` keeps only TINs equal to the
taxpayer's or spouse's (`TRCS:36027-36033`), and the UI pre-fills the active tab's SSN into a new statement
(`us-tax-ui/src/app/service/statement-entry-state.service.ts:26-35`). It **does** occur for a blank TIN (D-2a-3).

## 4. How it is computed

Methods:

- Load: `TRCS:3114-3118` (1099-INT, through `CommunityProperty.withCommunityPropertySplit`, which splits boxes 1, 3, 8
  and withholding only on an MFS return with community property = Yes), `TRCS:3119-3126` (1099-DIV), `TRCS:3250`
  (1099-OID, not split).
- Form 8814 line 1b total: `TRCS:3690-3694`.
- Call: `TRCS:3727-3745` → `computeInterestIncome` `TRCS:18875-19160` → `computeInterestForPerson` (once for taxpayer,
  once for spouse) `TRCS:19162-19522`.
- Attribution: `belongsToPerson` `TRCS:36021-36040`.
- Output: `buildIncome` `TRCS:18443`, `TRCS:18631-18633`.

Steps, mirroring `new_lines/2a.md` section 6:

1. **Collect the statements that belong on this return.** All household 1099-INT / OID / DIV rows are passed to both
   person passes. `belongsToPerson`:
   - If the statement has a recipient TIN: the taxpayer pass keeps it only if it equals `you.ssn`; the spouse pass only
     if it equals `spouse.ssn` (`TRCS:36027-36033`). A dependent's statement (TIN = dependent's SSN) matches neither
     and is dropped — correct.
   - If the TIN is blank: the taxpayer pass keeps it unless only the spouse answered Yes to "Did you have any interest
     income" (`TRCS:36036-36039`). On an MFS leg the spouse form and SSN are nulled (`TRCS:18910-18911`, `:18949`), and
     on a dependent's own return no interest form exists, so a blank-TIN statement is kept as "the taxpayer's" on
     **every** return of the household (D-2a-3).
   - On a dependent's own return `you.ssn` is the dependent's SSN (`us-tax-be/.../multireturn/DependentOwnFormScoper.java:155-164`),
     so the dependent's own statements are kept.
2. **Add 1099-INT box 8, not box 9.** Per statement `subtractNonNegative(box8, box13)` (`TRCS:19225`) — box 9 goes
   only to `form6251Line2g` (`TRCS:19229`). Match.
3. **Subtract tax-exempt premium.** Box 13 per statement (above, floored at 0 per statement). The hand-entered
   `taxExemptBondPremiumAdjustmentNotInStatements` is subtracted from the person's total, floored at 0
   (`TRCS:19399-19401`, `:19431`), unless `payerAlreadyReportedNetInterestOrOid` is Yes (`TRCS:18957-18958`).
4. **Add tax-exempt OID.** Box 11 per 1099-OID (`TRCS:19251`, `:19258`). The user-entered tax-exempt part of box 2
   (`taxExemptStatedInterestFrom1099OidBox2`) is added to 2a (`TRCS:19339`) and removed from the pooled box 2 total that
   goes to 2b (`TRCS:19334-19336`); a value larger than the person's box 2 total raises the blocking flag
   `OID_BOX2_TAX_EXEMPT_EXCEEDS_TOTAL_<PERSON>` (`TRCS:19298-19316`). **Box 10 and box 6 of a tax-exempt OID bond are
   subtracted from the taxable OID (box 1 + box 8), floored at 0, never from line 2a** (`TRCS:19253-19255`) (D-2a-2).
5. **Add exempt-interest dividends.** 1099-DIV box 12 for statements the person owns (`TRCS:19279-19285`); box 13 goes
   to Form 6251 line 2g via the dividend pass (`TRCS:19030`).
6. **Add other tax-exempt interest.** `manualTaxExemptInterestNotOnStatements` (`TRCS:19343-19345`). Then, at return
   level, the two persons are added (`TRCS:18987`) and the Form 8814 line 1b total of the elected children
   (`TRCS:18998`). K-1 tax-exempt interest is **not** added (D-2a-1).
7. **Round.** Each person's total is rounded (`TRCS:19515`), then the return total again (`TRCS:19143`) and once more in
   `buildIncome` (`TRCS:18443`) — `roundMoney` is half-up to whole dollars. Rounding each person first can differ by
   $1 from rounding only the total (see D-2b-8).
8. **Output.** `Income.taxExemptInterest` is set only when not null (`TRCS:18631-18633`): null when no input exists,
   0 when an entered value nets to zero. Not added into line 9 (`TRCS:18571`).

## 5. Flags and advisories

| Code | Blocks? | When | Tells the user | Where |
|---|---|---|---|---|
| `OID_BOX2_TAX_EXEMPT_EXCEEDS_TOTAL_TAXPAYER` / `_SPOUSE` | Yes (§17, not overrideable) | Tax-exempt part of 1099-OID box 2 > that person's box 2 total | Reduce the entry or upload the missing 1099-OID | `TRCS:19298-19316` |
| `INTEREST_STATEMENT_UPLOAD_REQUIRED` | Yes | Interest = Yes but no 1099-INT / DIV / OID and no confirmation (exceptions: seller-financed only, no-1099 interest only) | Upload statements | `TRCS:19582-19611` |
| `MISSING_UPLOADED_1099_INT` / `_DIV` / `_OID` | Yes | Marked as received, none uploaded | Upload it | `TRCS:19616-19640` |
| `COMMUNITY_PROPERTY_STATE_UNANSWERED` / `COMMUNITY_PROPERTY_ALLOCATION_APPLIED` | No | MFS in a community property state | Split not done / done | `us-tax-be/.../microservices/CommunityProperty.java:42-47`, `:98-104` |

No flag covers a statement with a blank recipient TIN or a TIN that matches neither filer.

## 8. Compared with the IRS rules

| # | IRS rule (source) | What the app does | Result |
|---|---|---|---|
| 1 | Total tax-exempt interest: 1099-INT box 8, 1099-OID box 11 (and box 2 for a tax-exempt OID bond), 1099-DIV box 12 (`i1040gi_ty2025.pdf p. 25`) | All four added (`TRCS:19225`, `:19258`, `:19284`, `:19339`) | Match |
| 2 | Box 9 / DIV box 13 are inside box 8 / box 12 — not added (`p17.pdf p. 63`) | Not added; to Form 6251 line 2g (`TRCS:19229`, `:19030`) | Match |
| 3 | Net of amortized premium on a tax-exempt bond (`i1040gi_ty2025.pdf p. 25`; box 13 `i1099int.pdf p. 4`) | 1099-INT box 13 subtracted per statement, floor 0; hand-entered premium subtracted unless "already netted" | Match |
| 4 | Net of premium on a tax-exempt **OID** bond: 1099-OID box 10 ("For a tax-exempt covered security … bond premium amortization allocable to the interest", `i1099int.pdf p. 7`) and box 6 acquisition premium (`i1099int.pdf p. 6`; `i1040gi_ty2025.pdf p. 25`) | Box 6 and box 10 are subtracted from box 1 + box 8 (taxable OID), floored at 0 (`TRCS:19253-19255`). On a tax-exempt OID bond box 1 is normally blank, so the premium is lost and line 2a keeps the gross box 2 / box 11 — line 2a overstated by the premium (the hand-entered `taxExemptBondPremiumAdjustmentNotInStatements` can work around it). On a taxable OID bond box 10 nets against box 1 instead of box 2: same total unless a floor bites | **Deviation D-2a-2** |
| 5 | K-1 tax-exempt interest: Form 1065 box 18 code A, Form 1120-S box 16 code A "include this amount on Form 1040 … line 2a" (`i1065sk1.pdf p. 25`; `i1120ssk.pdf p. 15`) | Stored (`ScheduleK1Form1065Mapper.java:237-242`, `ScheduleK1Form1120sMapper.java:220-222`), never read by compute; no flag | **Not supported D-2a-1** (silent; line 2a and every add-back understated) |
| 6 | Only your (and on a joint return your spouse's) interest; a child's custodial-account interest is the child's (`p17.pdf p. 57-58`) | Statements whose TIN is a dependent's are dropped (`TRCS:36027-36033`) — correct. A statement with a **blank** TIN is "the taxpayer's" on every return: on both MFS legs and on every dependent's own return, so it is counted two or more times; no flag (`TRCS:36036-36039`; contrast `MFS_W2_MISSING_EMPLOYEE_SSN` for W-2s) | **Deviation D-2a-3** (same root cause as D-1a-1 and D-2b-2) |
| 7 | Community property, MFS: half of community interest on each return (`p17.pdf p. 60`) | 1099-INT box 8 is split, but box 13 is not (the filer's own statement subtracts its full premium from half its box 8; the other spouse's copy carries no premium); 1099-DIV box 12 and 1099-OID box 11 are not in the split key lists (`TRCS:3114-3126`, `:3250`) | **Deviation D-2a-4** (low) |
| 8 | Market discount on a tax-exempt bond is taxable, not 2a (`i1040sb.pdf p. 1`) | Never added to 2a (market discount reaches only line 2b, `TRCS:19268-19276`) | Match |
| 9 | IRA / HSA / MSA / Coverdell interest not on 2a (`i1040gi_ty2025.pdf p. 25`) | No input path adds it | Match |
| 10 | Form 8814: child's tax-exempt interest on Form 8814 line 1b (`i8814.pdf p. 2-3`) | Form 8814 line 1b of every elected child is added to the parent's line 2a (`TRCS:3690-3694`, `:18998`) | Unverified — no 2025 IRS document in `docs\books` says line 1b is also entered on the parent's line 2a (the code comment quotes such a sentence, but it is not in `i8814.pdf`; the Form 8814 form itself is not in the library) |
| 11 | Rounding: round only the total (`i1040gi_ty2025.pdf p. 23`) | Each person rounded, then the total (`TRCS:19515`, `:19143`) | Deviation (cosmetic, ±$1) — recorded once as D-2b-8 |
| 12 | Line 2a is information only — not in line 9 (`p17.pdf p. 62`) | Not in the line 9 sum (`TRCS:18571`) | Match |

## 9. Limits and out of scope

- No IRMAA or state computations use line 2a.
- Tax-exempt interest from a Schedule K-1 (Form 1041) has no dedicated box; not modelled.
- The tax-exempt part of 1099-OID box 2 is one amount per person, not per statement.
- Deliberate design: three-state value — null (no input), 0 (input nets to zero), positive
  (`TRCS:19133-19141`; `knowledge/canonical-null-zero-semantic.md`).
