IRS rules: `C:\us-tax\new_lines\4c.md`. Flowchart: `C:\us-tax\new_flowcharts\4c.md`. Inputs and the shared IRA
computation: `new_knowledge\4b.md`. Paths are relative to `C:\us-tax`. `TRCS` =
`us-tax-be/src/main/java/com/ustax/microservices/TaxReturnComputeService.java`.

---

## 1. Status

Line 4c is computed: three booleans and a write-in text, each person's facts OR-ed into one return-level box. Box 1
follows the rollover answer, box 2 the QCD answer (after the age-70½ test), box 3 the HFD answer or a user write-in,
with "HFD" written automatically. A breakout statement is required (blocking flag) when more than one exception
applies, except Exception 2 plus exactly one other. **2 differences** (D-4c-1, D-4c-2), both disclosure-only: the
one-time QCD to a split-interest entity does not check box 3 / write "SIE", and a code G 1099-R alone does not check
box 1.

## 4. How it is computed

1. Per person (`computeIraForPerson`): `hasRollover` = rollover Yes or amount > 0; `hasQcd` = QCD Yes or amount > 0;
   `hasHfd` likewise; `hasOtherLine4cWriteIn` = write-in Yes, text or amount (`TRCS:21033-21041`). A rollover barred by
   the one-per-year rule and a QCD failing the 70½ test are removed beforehand, so their boxes stay unchecked
   (`TRCS:20119-20125`). Box-3 text = "HFD", then "; " and the write-in text (`TRCS:21193-21200`).
2. Return level: box 1 = either person's rollover, box 2 = either QCD, box 3 = either HFD / write-in, text joined and
   de-duplicated (`TRCS:20171-20175`). On MFS the spouse form is null (`TRCS:20113`).
3. Statement: category count = boxes checked + 1 if any Form 8606 trigger (`TRCS:20177-20190`). If the user answered
   "more than one exception" Yes, the statement is required unless they answered "only Exception 2 plus one other"
   Yes; otherwise required when the count > 1 and not (count = 2 with Exception 2) (`TRCS:20209-20216`). Required and
   not prepared → blocking `LINE4_EXCEPTION_BREAKOUT_STATEMENT_REQUIRED` (`TRCS:20217-20244`); the text "Line 4b
   Exception Breakdown: Rollover $…; QCD $…; HFD $…; … Exception 2 (see Form 8606)" is built (`TRCS:20350-20404`).
4. Output: each box set to `true` only when true (else left null), text and statement fields copied
   (`TRCS:18665-18694`).

## 8. Compared with the IRS rules

| # | IRS rule (source) | What the app does | Result |
|---|---|---|---|
| 1 | Box 1 when Exception 1 applies (`i1040gi_ty2025.pdf p. 27–28`) | From the rollover answer | Match |
| 2 | A traditional-IRA amount paid directly to an employer plan is a rollover (1099-R code G, box 2a 0, `i1099r--2025.pdf p. 13`) | Box 1 only if the user also answers the rollover question; a code G 1099-R is used for Form 8606 line 7 (`TRCS:20969`, `:21364`) but not for the box | **Deviation D-4c-2** (box unchecked) |
| 3 | Box 2 when Exception 3 applies | From the QCD answer, after the 70½ test | Match |
| 4 | Box 3 + "HFD" when Exception 4 applies | Automatic "HFD" | Match |
| 5 | Box 3 + any word another publication requires; one-time QCD to an SIE: "Check box 3 on line 4c and enter "SIE"" (`i1040gi_ty2025.pdf p. 28`; `p590b.pdf p. 14`) | Free write-in supported, but the SIE answer only raises the attachment flag and text; box 3 and "SIE" are not set (`TRCS:20289-20348`) | **Deviation D-4c-1** |
| 6 | No box for Exception 2 | None | Match |
| 7 | More than one exception → statement; not needed for Exception 2 + one other (`i1040gi_ty2025.pdf p. 28`) | Auto-count or user assertion; blocking flag | Match (box 3 HFD + another write-in count as one category — no IRS text either way) |
| 8 | Joint return: one set of boxes; MFS: own facts | OR of both; spouse null on MFS | Match |
