# Form 1040 line 5a — how the app does it

IRS rules: `C:\us-tax\new_lines\5a.md`. Flowchart: `C:\us-tax\new_flowcharts\5a.md`. The taxable amount (line 5b) is
in `new_knowledge\5b.md`, the checkboxes in `new_knowledge\5c.md`.
Paths are relative to `C:\us-tax`. `TRCS` = `us-tax-be/src/main/java/com/ustax/microservices/TaxReturnComputeService.java`.

---

## 1. Status

Line 5a is computed. For each spouse the app adds box 1 of every Form 1099-R whose IRA/SEP/SIMPLE box is not checked
and whose recipient TIN is that spouse's, plus Form RRB-1099-R box 7 (or boxes 4 + 5 + 6). It leaves out 1099-Rs the
user routed to line 1h as a disability pension before the minimum retirement age, and codes 8 / P (corrective
distributions). Line 5a is left blank when the whole return's pensions are fully taxable and no exception applies.
Form 4852 line 8a (non-IRA 1099-R substitutes) is added afterwards, and a Form 4972 lump sum is taken out at the end.

**Unlike line 1a (D-1a-1), the person filter runs on every filing status**: a dependent's Form 1099-R that carries the
dependent's SSN as recipient TIN never reaches the parent's line 5a. The same root cause survives only for a 1099-R or
RRB-1099-R saved **without** a recipient TIN, which is given to the taxpayer of whatever return is computed (D-5a-1).

**5 differences from the IRS rules** (D-5a-1 … D-5a-5). D-5a-1 and D-5a-2 change amounts (line 5b too); D-5a-3 …
D-5a-5 affect only the line 5a figure, which is not part of total income.

## 4. How it is computed

Methods:

- Load: `TRCS:3110-3113` — `listEntriesWithData(uid, "1099-r")` / `"rrb-1099-r"`, through
  `CommunityProperty.split1099R` / `splitRrb1099R` (MFS community-property split by the pension percentage).
- Orchestrator `computePensionAnnuities` `TRCS:21529-21935`; per person `computePensionForPerson` `TRCS:21937-22440`.
- Attribution: `belongsToPersonByTinAndFallback` `TRCS:36002-36019` (1099-R), `belongsToPersonRrb1099R`
  `TRCS:35933-35950`.
- Form 4852: `extractForm4852RetirementSubstitute` `TRCS:46829-46859`, `augmentPensionWithForm4852`
  `TRCS:46967-47006`, called `TRCS:3783-3788`.
- Form 4972: `adjustPensionLinesForForm4972` `TRCS:52022-52083`, called `TRCS:6067-6094`.
- Assembly: `buildIncome` `TRCS:18455` (rounded), `TRCS:18695-18697` (output).

Steps, mirroring `new_lines/5a.md` §6:

1. **Collect the statements of this return.** Every 1099-R and RRB-1099-R of the account is loaded. Per person:
   - A 1099-R with a recipient TIN counts for the taxpayer when it equals `you.ssn`, for the spouse when it equals the
     spouse's SSN (`TRCS:36008-36014`). The spouse SSN is nulled on MFS (`TRCS:21644`), so the other spouse's 1099-R
     is dropped there. **This runs on every filing status**, so a dependent's 1099-R (TIN = the child) is never on the
     parent's return; on a dependent's own return `you` is the dependent (`multireturn/DependentOwnFormScoper.java:150-160`)
     and the child's 1099-R is counted there.
   - A 1099-R **without** a TIN goes to the taxpayer unless only the spouse answered "had pension" Yes
     (`TRCS:36015-36018`); the RRB rule is the same (`TRCS:35946-35949`). With no spouse form (MFS, dependent's own
     return, single) the taxpayer always gets it — on every return computed from the account (D-5a-1).
2. **Remove what belongs elsewhere.** IRA/SEP/SIMPLE checked → skipped (`TRCS:21980`, it goes to 4a/4b). A 1099-R
   whose `entryId` the Other earned income form answered "below minimum retirement age" → skipped (`TRCS:21656-21667`,
   `:21990-21993`; it is on line 1h). Codes 8 or P without code 3 → skipped (`TRCS:22001-22004`).
3. **Add box 1.** `gross1099R` sums `grossDistributionAmount` (`TRCS:22014`). RRB: box 7 when present, else
   box 4 + 5 + 6 (`TRCS:22094-22098`). `grossTotal` = both (`TRCS:22147`), rounded per person (`TRCS:22431`); the two
   spouses are added (`TRCS:21781`).
4. **Blank when fully taxable.** Line 5a is null when the **return-wide** gross equals the return-wide taxable amount,
   both are positive and neither spouse has an "exception": rollover, PSO, write-in, a box 2b entry or the
   "taxable amount blank" answer, Simplified Method or General Rule (`TRCS:21797-21802`, exceptions
   `TRCS:22312-22317`). Otherwise line 5a = rounded gross. A box-2b entry keeps line 5a printed even when nothing is
   tax free (D-5a-5).
5. **Form 4852 1099-R substitutes.** Non-IRA entries' line 8a / 8b are added to line 5a / 5b (taxpayer; spouse unless
   MFS) (`TRCS:46845-46852`, `:46979-46989`). The "fully taxable" test is redone, but the starting gross is the
   **already-blanked** line 5a, so a fully taxable 1099-R's gross is lost when a partly taxable Form 4852 joins it
   (D-5a-3). Nothing removes the Form 1099-R a Form 4852 replaces (D-5a-2).
6. **Form 4972.** After line 15 is final: Part III → line 5a − box 1 of the lump sum; Part II only → line 5a − box 3;
   line 5a set to null when it reaches 0 or equals line 5b (`TRCS:52037-52078`). With Part II only, IRS wants the
   ordinary-income portion (box 2a − box 3) on line 5a; the app leaves box 1 − box 3 (D-5a-4).
7. **Round / output.** `roundMoney` half-up to whole dollars, per person and again on the total (`TRCS:22431`,
   `:21802`, `:18455`); see `5b.md` D-5b-14.

## 8. Compared with the IRS rules

| # | IRS rule (source) | What the app does | Result |
|---|---|---|---|
| 1 | Line 5a = box 1 of the non-IRA Forms 1099-R (`i1040gi_ty2025.pdf p. 28`) | Sums `grossDistributionAmount` of non-IRA entries (`TRCS:21980`, `:22014`) | Match |
| 2 | Only your (and on a joint return your spouse's) distributions; a child's income is the child's (`i8814.pdf p. 1`) | TIN filter on every filing status (`TRCS:36008-36014`) | Match (D-1a-1 does not repeat) |
| 3 | Same, for a statement saved without a recipient TIN | Given to the taxpayer of every computed return — the parent's, each MFS leg, a dependent's own return (`TRCS:36015-36018`, `:35946-35949`); no flag. The RRB-1099-R id is not pre-filled from the active tab, so an RRB-1099-R typed on a spouse / dependent tab without box 2 lands on the taxpayer | **Deviation D-5a-1** (same root cause as D-1a-1; silent) |
| 4 | Fully taxable → line 5a blank (`i1040gi_ty2025.pdf p. 28`; `f4972.pdf p. 2`) | Return-wide test (`TRCS:21797-21802`) | Match |
| 5 | More than one pension, any partly taxable → line 5a = all payments (`i1040gi_ty2025.pdf p. 29`) | Gross of all entries | Match |
| 6 | A box 2b entry with no cost is still fully taxable → line 5a blank | `hasTaxableNotDetermined` counts as an "exception" (`TRCS:22151-22152`, `:22315`) and line 5a prints | **Deviation D-5a-5** (cosmetic) |
| 7 | Disability pension before minimum retirement age → line 1h (`i1040gi_ty2025.pdf p. 25, p. 28`) | Skipped when answered Yes on the Other earned income form (`TRCS:21656-21667`, `:21990-21993`) | Match (IRA code 3: see D-1h-6) |
| 8 | Corrective distributions → line 1h; code P → earlier year (`i1040gi_ty2025.pdf p. 28`) | Codes 8 / P skipped (`TRCS:22001-22004`) | Match |
| 9 | IRA distributions → lines 4a/4b | `iraSepSimple == true` skipped; null blocks (`TRCS:21980`, `:23200-23235`) | Match |
| 10 | RRB tier 2 / NSSEB / VDB are pension income (`p525.pdf p. 35`) | Box 7 or 4+5+6 (`TRCS:22087-22121`) | Match (box 6 supplemental annuity counted; Pub. 575 not in the source set — unverified) |
| 11 | Rollover: full box 1 on line 5a (`i1040gi_ty2025.pdf p. 30`) | Box 1 counted; rollover makes line 5a print | Match |
| 12 | Form 4852 replaces a missing or **incorrect** 1099-R (`f4852.pdf p. 1`) | Line 8a / 8b added; the incorrect 1099-R still counts (`TRCS:46829-46859`, `:46967-47006`) | **Deviation D-5a-2** (double count on 5a and 5b if kept; same as D-1a-6) |
| 13 | Line 5a = total payments when not all are fully taxable | Form 4852 merge starts from the blanked line 5a, dropping a fully taxable 1099-R's gross (`TRCS:46979`, `:46989`): 1099-R $10,000 fully taxable + Form 4852 $5,000 / taxable $3,000 → line 5a $5,000, line 5b $13,000 (should be $15,000) | **Deviation D-5a-3** (cosmetic) |
| 14 | Form 4972 Part III: no part on 5a/5b; Part II only: ordinary portion (box 2a − box 3) on 5a and 5b (`f4972.pdf p. 2`) | Part III: box 1 removed (Match). Part II only: line 5a − box 3 (`TRCS:52046-52049`), so line 5a keeps box 1 − box 3 | **Deviation D-5a-4** (cosmetic) for Part II |
| 15 | Rounding: round only the total (`i1040gi_ty2025.pdf p. 23`) | Rounded per spouse, then the sum | Minor (see D-5b-14) |
| 16 | Separate returns: own statements; community property split | MFS spouse SSN nulled; `CommunityProperty.split1099R` | Match |

## 9. Limits and out of scope

- **Line 5a never feeds a total**; differences D-5a-3 … D-5a-5 change only the printed figure and the IRS matching.
- **Form 1099-R `ownerRole`** is stored but not read; attribution is by recipient TIN only.
- **Line-1h routing** is driven by the Other earned income form; the pension form's disability question only raises a
  confirmation flag.
- **Pub. 575 / Pub. 939 / Pub. 721** are not in the 2025 source set; RRB box-level treatment and Civil Service
  alternative annuities are taken as the code has them (unverified).
