# Form 1040 line 5b — how the app does it

IRS rules: `C:\us-tax\new_lines\5b.md`. Flowchart: `C:\us-tax\new_flowcharts\5b.md`. Which statements reach
lines 5a/5b, attribution and storage of the statements: `new_knowledge\5a.md` (read §2–§4 there first).
Paths are relative to `C:\us-tax`. `TRCS` = `us-tax-be/src/main/java/com/ustax/microservices/TaxReturnComputeService.java`.

---

## 1. Status

Line 5b is computed per **person** (taxpayer, spouse), not per pension: the person's non-IRA Forms 1099-R and RRB-1099-R
are pooled, a single taxable figure is built from the pool, and the two spouses are added. The pool's starting figure
is the sum of box 2a (box 1 when **no** entry has a box 2a), plus RRB boxes 4 + 5 + 6. That figure is then replaced by,
in order: the per-annuity-stream worksheets (when the user filled "More than one pension"), else the person-level
Simplified Method and/or General Rule; then — if the user reported a rollover — **recomputed from box 1** as
box 1 − rollover − box 5; then reduced by the PSO exclusion. Form 4852 1099-R substitutes are added and a Form 4972
lump sum is removed later.

Supported: Simplified Method (Table 1 after-Nov-18-1996 column, Table 2, prior recovery cap, RRB box 3 as cost, age
from the dates), General Rule (exclusion ratio rounded to 3 places, Pub. 939 Table V expected return, lifetime cap),
per-annuity streams, rollovers, PSO, NUA election, box 2b basis netting, codes 8 / P and line-1h routing.

**14 differences from the IRS rules** (D-5b-1 … D-5b-14). The most serious, all silent:
a Form 1099-R with a blank box 2a is dropped from line 5b when another 1099-R of the same person has a box 2a
(D-5b-1); a reported rollover throws away the Simplified Method / General Rule / per-stream result and the NUA
exclusion (D-5b-2); a rollover into a Roth IRA is treated as tax free (D-5b-3); the PSO exclusion is a full $3,000
when the premiums field is left blank (D-5b-4).

## 4. How it is computed

Methods (all in `TRCS` unless noted):

- `computePensionAnnuities` `21529-21935` → pre-processing `withSimplifiedMethodRrbCostAndAge` `22983-23032`,
  `withTableVExpectedReturn` `22729-22780`; per person `computePensionForPerson` `21937-22440`; aggregation
  `21780-21803`.
- Worksheets: `computePensionTaxableViaSimplifiedMethod` `22447-22473`, `determineSimplifiedMethodFactor`
  `22798-22833`, `computePensionTaxableViaGeneralRule` `22636-22653`, `capGeneralRuleExclusionAtUnrecoveredCost`
  `22662-22678`, `computePensionTaxableViaPerStream` `22490-22522` (+ `computePerStreamSimplifiedTaxable`
  `22524-22552`, `computePerStreamGeneralRuleTaxable` `22554-22571`, `sumStreamGrossAmounts` `22574-22592`).
- Later: `augmentPensionWithForm4852` `46967-47006`; `adjustPensionLinesForForm4972` `52022-52083` with the cascade
  `6059-6094`. Output `buildIncome` `18456`, `18698-18700`; line 9 `18571`.

Steps, mirroring `new_lines/5b.md` §6 (the IRS figures each pension separately; the app figures each **person**):

1. **Pool the person's statements** (routing and attribution as `5a.md` §4 steps 1–2). For each kept 1099-R:
   `gross1099R += box 1`; `taxable1099R += box 2a` **only when box 2a is filled** (`TRCS:22014-22015`); box 5 summed
   (`:22026`), and separately for box-2b entries (`:22027-22031`); with the NUA election and a filled box 2a, box 6 is
   added to `taxable1099R` (`:22020-22025`). RRB: taxable = box 4 + 5 + 6 (box 4 fully taxable until a worksheet
   runs), else box 7; boxes 5 + 6 kept apart as non-contributory; box 3 and box 4 kept for the cap (`:22087-22121`).
2. **Starting figure.** `taxableBase = (taxable1099R, or gross1099R when taxable1099R is null) + taxableRrb`
   (`:22147-22149`). The box 1 fallback applies only when **no** entry of the person has a box 2a; an entry with a
   blank box 2a next to one with a box 2a contributes nothing (D-5b-1). There is no requirement to pick a worksheet
   when box 2a is blank (D-5b-13).
3. **Per-annuity streams** (when `annuityStreams[]` is non-empty, `:22175-22183`): each stream's taxable figure is
   computed from its own inputs (Simplified: cost ÷ factor × months, capped at cost − prior recovery; General: payments
   × ratio, ratio = cost ÷ expected return rounded to 3 places, capped at the unrecovered cost unless the start is
   before 1987; no method → stream gross). `taxableBase = Σ stream taxable + (person's box 1 total − Σ stream gross)`:
   statements not covered by a stream count at **box 1**, not box 2a (D-5b-7). Incomplete stream inputs → stream gross,
   no flag (`:22528-22535`).
4. **Simplified Method, person level** (no streams, `needsSimplifiedMethodComputation`, `:22185-22209`):
   - Base = all of the person's box 1 + RRB gross − RRB boxes 5/6 (`:22189`). Cost blank → RRB box 3 total with an
     advisory; age replaced by the age from the starting date and date of birth (`:22983-23032`).
   - Factor: Table 2 whenever a survivor age > 0 (410/360/310/260/210 by combined age), else Table 1 **after Nov 18,
     1996** column (360/310/260/210/160); no age → 360 (`:22798-22833`). The before-Nov-19-1996 column is never used and
     the post-1997 condition for Table 2 is not checked (D-5b-8).
   - Exclusion = cost ÷ factor × min(months, 12), capped at cost − prior recovery; prior recovery ≥ cost → fully taxable
     (`:22449-22472`). A pre-1987 start is still capped at the cost (D-5b-8). The cost is used as typed; the UI help tells
     the user to type it **net** of prior recoveries and to count a quarterly pension as **4** (D-5b-9).
   - RRB cap (B49): when the cost equals RRB box 3, the tax-free part cannot exceed box 4 (`:22196-22204`).
   - Result + RRB boxes 5/6 replaces `taxableBase` (`:22205`). It is applied to **all** the person's statements together
     (D-5b-6); `PENSION_BASIS_RECOVERY_PER_ANNUITY_LIMITATION_*` blocks (overridable) when the person has 2+ statements.
5. **General Rule, person level** (`needsGeneralRuleComputation`, `:22210-22216`): expected return from Table V when
   blank (one life, `:22729-22780`); taxable = **typed payments received** − payments × ratio (capped at unrecovered
   cost). The result **replaces** `taxableBase` — every other 1099-R and RRB amount of the person is dropped, and box 1
   is ignored in favour of the typed payments (`:22651`) (D-5b-6). With both methods ticked the General Rule wins after a
   blocking flag.
6. **Rollover** (`hadPensionRollover` or an amount, `:22226-22252`): `taxable = max(0, Σ box 1 − (rollover + box 5)) +
   RRB taxable`, where box 5 is the typed "after-tax contributions" figure or, when blank, the sum of box 5 of **all**
   the person's 1099-Rs. This **discards** the worksheet / stream / box 2a result of step 2–5 and puts NUA (in box 1)
   back into income (D-5b-2). There is no question about the destination, so a rollover into a Roth IRA or designated
   Roth account is subtracted like any other (D-5b-3) — the screen says "Rolled-over amounts are not included in your
   taxable income" (`:375`).
7. **Box 2b basis** (no rollover, no worksheet, `:22253-22263`): the box 5 of box-2b entries is subtracted.
8. **PSO** (`isEligibleRetiredPublicSafetyOfficer` and `electsPsoPremiumExclusion`, `:22277-22284`): exclusion =
   `minNonNull(premiums, 3000)` (`TRCS:52408-52416`), so a **blank** premium gives $3,000 (D-5b-4); subtracted from the
   person's whole taxable pension, floored at 0. Not checked: governmental plan of the employer retired from, and the
   medical deduction bar (D-5b-5). The line-1h PSO has its own $3,000 (D-1h-9).
9. **Aggregate and round.** Each person `roundMoney(taxableAfterPso)` (`:22432`), the two added and rounded
   (`:21782`, `:21803`) (D-5b-14). Codes 1 / S feed Form 5329 through `PensionEarlyDistributionBase` (box 2a, or box 1
   on the fallback, or the worksheet share), then rollover and PSO netting (`:22219-22224`, `:22329-22363`).
10. **Form 4852** (`TRCS:3783-3788`): non-IRA line 8b added (taxpayer; spouse unless MFS); no worksheet, PSO or code
    routing for it (see `5a.md` D-5a-2, D-5a-3).
11. **Form 4972** (after line 15, `TRCS:6059-6094`): Part III → line 5b − box 2a (− elected NUA); Part II only →
    line 5b − box 3; floored at 0; the same amount is taken off line 9, AGI and line 15. Figures already computed from
    AGI (taxable social security, phase-outs, the medical floor) are not redone (D-5b-11; detail in a later
    `forms/4972` file).
12. **Output.** `Income.taxablePensionsAnnuities`; 0 is kept when a full rollover / exclusion nets to zero
    (`TRCS:21906-21914`).

Not modelled: the Simplified Method Worksheet itself (lines 10–11) is neither shown nor carried to next year
(D-5b-10); the death-benefit exclusion; Civil Service alternative annuity; a spouse-only pension on a joint return trips
the taxpayer-form upload gate (D-5b-12).
