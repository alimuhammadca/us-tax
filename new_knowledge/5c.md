# Form 1040 line 5c — how the app does it

IRS rules: `C:\us-tax\new_lines\5c.md`. Flowchart: `C:\us-tax\new_flowcharts\5c.md`. Amounts: `5a.md`, `5b.md`.
Paths are relative to `C:\us-tax`. `TRCS` = `us-tax-be/src/main/java/com/ustax/microservices/TaxReturnComputeService.java`.

---

## 1. Status

All three boxes and the box 3 text are produced from the Pension withdrawals forms (taxpayer + spouse; spouse ignored
on MFS) and OR-ed into one set per return. Box 1 = a rollover was reported; box 2 = the PSO exclusion was elected;
box 3 = a write-in text or amount was typed. Nothing is derived from the Forms 1099-R themselves.
**2 differences** (D-5c-1, D-5c-2), both cosmetic.

## 3. How it is computed

Per person in `computePensionForPerson` (`TRCS:21937`):

- `hasRollover` = `hadPensionRollover == true` **or** a positive rollover amount (`TRCS:22226-22227`).
- `hasPsoElection` = eligible **and** elects (`TRCS:22277-22279`) — premiums are not required.
- Box 3 text = "text $amount", "text", or "$amount" (`TRCS:22296-22307`); the box is on when the flag, text or amount is
  set (`:22308-22310`).

Return level (`TRCS:21775-21778`): box 1 = taxpayer OR spouse; box 2 = taxpayer OR spouse; box 3 text = both texts
split on ";" and de-duplicated (`joinOtherWriteInTokens`, `TRCS:35964-35995`); box 3 = text present. On MFS the spouse
form is null (`TRCS:21565`). Any of the three makes line 5a print and keeps the pension record even when line 5b is 0
(`TRCS:21906-21911`). Form 4852-only pensions get all three false (`TRCS:46990-46996`).

## 7. Compared with the IRS rules

| # | IRS rule (source) | What the app does | Result |
|---|---|---|---|
| 1 | Box 1 for any rollover, "including a direct rollover" (`i1040gi_ty2025.pdf p. 30-31`) | Only when the user answers Yes / types an amount. A code-G direct rollover (box 2a = 0) with the question left No: line 5a = box 1, line 5b = 0, box 1 **unchecked**; the code-G count is shown only as a hint (`form-pension-annuity-income-taxpayer.component.ts:377-380`) | **Deviation D-5c-1** (cosmetic) |
| 2 | Box 2 when "making the election" to exclude premiums (`i1040gi_ty2025.pdf p. 31`) | Checked when eligible + elected, even with premiums 0 (nothing excluded) or blank ($3,000 excluded — D-5b-4) (`TRCS:22279`) | **Deviation D-5c-2** (cosmetic; the amount error is D-5b-4) |
| 3 | Box 3 + the word or code from another instruction (`i1040gi_ty2025.pdf p. 31`) | Free text, optionally followed by "$amount" | Match (the appended amount is an app choice) |
| 4 | "Check each box that applies"; one set per return | OR across spouses; MFS spouse excluded | Match |
| 5 | A PSO exclusion on a line-1h disability pension is written next to line 1h, not on 5c (`i1040gi_ty2025.pdf p. 28, p. 30`) | Line-1h PSO does not touch box 2 (`TRCS:21776` reads only the pension forms) | Match (the line-1h write-in has no amount: D-1h-9) |

## 8. Limits

No 1099-R-driven defaults (codes G / H are not read by the compute). No statement for several exceptions (not required
by the 2025 instructions for line 5c).
