## 1. Status

Line 6d is computed: checked when the filing status is married filing separately and the "lived apart from your
spouse for the entire tax year" answer is Yes. On MFS the Filing status form's "lived together at any time in 2025"
answer, when given, overrides the Social Security form's two answers; an unanswered MFS return is treated as "lived
together" (box blank, $0 base) with an overrideable blocking flag; contradictory answers block. The box exists only
when the Social Security computation exists.

**1 difference** (D-6d-1, low): an MFS filer who lived apart all year but has no Social Security benefits gets no
line 6d box; the instruction sentence itself has no benefits condition (an interpretation point, cosmetic).

## 4. How it is computed

1. **One household answer on MFS** (`TRCS:2740-2815`): if the filing-status answer exists, both Social Security
   answers are overwritten with it (`TRCS:2747-2756`); else a Schedule R-only answer is used (`TRCS:2759-2767`); else
   both are set to "lived together", and `MFS_LIVED_WITH_SPOUSE_UNANSWERED` (blocking, overrideable) is raised when it
   matters (`TRCS:2768-2813`).
2. **Line 6d** = `isMfs && livedApartFromSpouseEntireTaxYear` (`TRCS:33890-33931`).
3. **Consistency**: MFS with benefits and both answers Yes or both not Yes → `SOCIAL_SECURITY_LINE6D_MFS_RESIDENCE_INCONSISTENT`
   (non-overrideable) (`TRCS:33957-33958`, `:34707-34753`).
4. The worksheet uses the **other** answer (`isMfs && livedWithSpouseAnyTime`) for the $0-base path (`TRCS:34094`);
   step 3 keeps the two consistent.
5. **Output** only inside the Social Security record (`TRCS:34288-34295`, `TRCS:18712-18715`): no benefits → no record
   → no box.

## 8. Compared with the IRS rules

| # | IRS rule (source) | What the app does | Result |
|---|---|---|---|
| 1 | Check line 6d if MFS and lived apart for all of 2025 (`i1040gi_ty2025.pdf p. 31`) | `isMfs && livedApartAllYear` (`TRCS:33931`) | Match |
| 2 | "All of 2025" — living together on any day fails (`i1040gi_ty2025.pdf p. 32`) | Question asked as "at any time … (even one day)"; unanswered → lived together | Match |
| 3 | Box and base amount describe the same fact (`i1040gi_ty2025.pdf p. 32`) | One household answer on MFS; contradictions block | Match |
| 4 | The line 6d sentence has no condition about benefits (`i1040gi_ty2025.pdf p. 31`) | No Social Security record → no box (`TRCS:33857-33859`) | **Deviation D-6d-1** (low, cosmetic; the box only affects the Social Security worksheet, so no amount changes) |

## 9. Limits and out of scope

- A married person filing as head of household (treated as unmarried) never gets the box, matching the worksheet.
