IRS rules: `C:\us-tax\new_lines\forms\3903.md`. Flowchart: `C:\us-tax\new_flowcharts\forms\3903.md`.
Paths are relative to `C:\us-tax`. `TRCS` = `us-tax-be/src/main/java/com/ustax/microservices/TaxReturnComputeService.java`.
`IA-UI` = `us-tax-ui/src/app/forms/form-income-adjustments-taxpayer.component.ts` (spouse copy:

---

## 1. Status

Form 3903 is **computed in short form but not produced**. Per person, the user types one amount — the full moving
costs (Form 3903 line 3) — and answers whether the move was an active-duty military move. The app reads that person's
W-2 box 12 code P (line 4) automatically, matching W-2s by the employee SSN. With "Yes" the deduction is line 3 − line 4,
not below zero, on **Schedule 1 line 14**; when code P is larger than the costs, the difference is added to
**Form 1040 line 1h**. An amount without "Yes" blocks the return. Lines 1 and 2 are not asked separately, the storage-
fees-only answer is saved but unused, and the Form 3903 tax-return preview is always blank — only an "attach Form
3903" marker exists.

**4 differences from the IRS rules** (D-3903-1 … D-3903-4). The most serious: when the moving costs are left blank (or
the active-duty answer is not Yes) a W-2 code P amount is never added to line 1h, although line 5 says the excess of
line 4 over line 3 is income (D-3903-1, silent); and Form 3903 itself never appears on the return (D-3903-3). The
line 14 storage-fees box is never checked — already recorded as D-10-14 (`new_knowledge/10.md`).

## 4. How it is computed

Methods:

- `withForm3903CodeP` `TRCS:10367-10386` — called in `prepare` (`TRCS:3584-3588`): copies the person's code P total
  into the adjustments map under `form3903GovernmentPaymentsCodeP` (`TRCS:10282`).
- `gatedMovingExpense` `TRCS:10410-10435` — Schedule 1 line 14 per person; summed at `TRCS:32865-32867`; output
  `TRCS:33263`.
- `form3903ExcessPayments` `TRCS:10392-10402` — the line 1h excess; used in `computeOtherEarnedIncome`
  (`TRCS:40204-40208`, statement label `TRCS:40247-40248`).
- Attachment marker: `buildLine10AttachmentForms` `TRCS:38228-38235`.

Steps, mirroring `new_lines/forms/3903.md` section 6:

1. **Certification.** `isActiveDutyMilitaryMoveLine14` must be true. If the moving amount is not zero and the answer is
   not true, the amount is dropped and the blocking flag `SCHEDULE1_LINE14_MOVING_EXPENSES_NOT_ACTIVE_DUTY_MILITARY_<side>`
   is raised (`TRCS:10428-10434`).
2. **Storage-fees-only shortcut.** Not modelled: `movingExpensesStorageFeesOnlyLine14` is stored but no compute code
   reads it; the amount is handled like any move, a Form 3903 marker is still created, and the Schedule 1 line 14 box
   is hard-coded unchecked (D-3903-2; box: D-10-14).
3. **Lines 1 and 2.** Not asked separately; the user types the line 3 total. The mileage rate (21 cents) and the
   exclusions (meals, government services, nondeductible items) are left to the user via the help text.
4. **Line 3.** `movingExpensesArmedForcesLine14`.
5. **Line 4.** `withForm3903CodeP`: for the taxpayer, every W-2 whose `employeeSSN` equals the taxpayer's SSN **or is
   blank**; for the spouse (not on MFS), every W-2 with the spouse's SSN; the box 12 code P amounts are summed
   (`sumW2Box12AmountForCode`, `TRCS:41279`). A dependent's W-2 (with its own SSN) is not picked up — the D-1a-1 root
   cause does not apply here.
6. **Line 5 (Yes branch).** Line 14 for the person = line 3 − code P, floored at 0 (`TRCS:10413-10426`), with the
   non-blocking advisory `FORM_3903_CODE_P_SUBTRACTED_<side>` reminding the user to enter the full costs. Schedule 1
   line 14 = taxpayer + spouse (`TRCS:32865-32867`); the spouse map is null on MFS (`TRCS:32782`).
7. **Line 5 (No branch).** `form3903ExcessPayments`: only when the active-duty answer is true **and** the costs are
   more than zero **and** code P is more than the costs, line 1h gets code P − costs (`TRCS:10393-10401`). Code P with
   blank or zero costs, or with the active-duty answer blank, adds nothing (D-3903-1).
8. **Form 2555 filers.** Nothing allocates the deduction to excluded income (D-3903-4).
9. **The form.** A `RequiredAttachmentForm` "Schedule 1 line 14 is used; attach Form 3903." with the combined line 14 is
   created when line 14 is not zero (`TRCS:38228-38235`; `us-tax-be/src/main/java/com/ustax/microservices/output/Form3903AttachmentMapper.java`).
   No Form 3903 with lines exists (D-3903-3).

## 8. Compared with the IRS rules

| # | IRS rule (source) | What the app does | Result |
|---|---|---|---|
| 1 | Only active-duty Armed Forces members moving under a military order / PCS (`f3903.pdf p. 1`; `i3903.pdf p. 1`) | Yes/No gate; amount without Yes blocks (`TRCS:10410-10435`) | Match |
| 2 | Line 3 = line 1 + line 2 (`f3903.pdf p. 1`) | One typed line 3 amount | Match (lines 1–2 not itemised; exclusions left to the user) |
| 3 | Line 4 = government payments not in W-2 box 1, shown in box 12 code P (`f3903.pdf p. 1`; `i3903.pdf p. 2`) | Code P summed per person by box a (`TRCS:10367-10386`); a W-2 with blank box a counts for the taxpayer | Match (edge: a spouse's or dependent's W-2 without box a is credited to the taxpayer) |
| 4 | Line 3 > line 4: line 5 = line 3 − line 4 → Schedule 1 line 14 (`f3903.pdf p. 1`) | `subtractNonNegative(costs, codeP)` (`TRCS:10426`) | Match |
| 5 | Line 3 ≤ line 4: line 4 − line 3, if more than zero, on Form 1040 line 1h (`f3903.pdf p. 1`; `i3903.pdf p. 1-2`) | Added only when costs > 0 and the active-duty answer is Yes (`TRCS:10393-10399`); code P alone, or with the answer blank, never reaches line 1h | **Deviation D-3903-1** (income understated, silent) |
| 6 | Storage fees only (earlier move, payment in W-2 box 1): do not file Form 3903; enter on Schedule 1 line 14 and check the box (`i3903.pdf p. 2`; `i1040gi_ty2025.pdf p. 93`) | Answer stored but unused; the Form 3903 marker is still created; the box is never checked (D-10-14) | **Deviation D-3903-2** (low; wrong attachment, amount right) |
| 7 | Attach Form 3903; one per move (`f3903.pdf p. 1`; `i3903.pdf p. 1`) | Only a combined marker; the preview is always blank and listed on every return; one amount per person, so two moves cannot be shown separately | **Deviation D-3903-3** (form missing from the return) |
| 8 | Form 2555 filer: the part allocable to excluded income is reported on Form 2555 (`i3903.pdf p. 2`; Pub. 54) | Not modelled; full deduction kept | **Not supported D-3903-4** (low; rare — a member's own military pay is not the excluded income) |
| 9 | Separate returns: the member's own costs and code P | Spouse map null on MFS (`TRCS:32782`); spouse code P not read on MFS (`TRCS:3587-3588`) | Match |
| 10 | Excess reimbursement is earned income on line 1h | Labelled "Excess moving reimbursement (Form 3903)" inside line 1h (`TRCS:40247-40248`) | Match |

## 9. Limits and out of scope

- The storage-fees-only path, the Schedule 1 line 14 box (D-10-14) and the MFS-lived-apart box on line 20 are covered in
  `new_knowledge/10.md`.
- D-1h-7 in `new_knowledge/1h.md` is about Form **1099-R** code P (excess deferrals returned after April 15), not W-2
  code P; it does not touch Form 3903.
- Moving expenses for civilians are not deductible for 2025 and have no input other than the refused amount.
