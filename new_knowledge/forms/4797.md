## 1. Status

Form 4797 is figured from several sources that all become "Form 4797 entries" (maps under the PDF-slot keys
`partiiiLine20PropertyAGrossSalesPrice` …) and run through one Part III loop
(`computeForm4797Part3Recapture`, `TRCS:2029-2290`):

- the **Business property sales** intake form (V377, 2026-10-23) — one Part III property per sale (`F4797S`);
- the Installment sales, Like-kind exchanges and Business casualties intake forms (lines 4, 5, 16, 3, 14 and Part III);
- depreciation assets whose business use fell to 50% or less (Part IV, derived);
- typed **Form 4797 statement entries** — the statement mapper **is active** (`formIds()` = `{"4797"}`,
  `us-tax-be/src/main/java/com/ustax/microservices/statement/Form4797Mapper.java:30-37`) and compute reads it
  (`TRCS:3155-3156`), but no screen offers it: the statement picker deliberately omits 4797
  (`us-tax-ui/src/app/service/statement-selection.service.spec.ts:64-66`), so this path is API-only. (Unlike
  `Form6252Mapper` and `Form8824Mapper`, which return an empty `formIds()` — see `8824.md`.)

Section 1245 recapture, section 1250 recapture (from a typed "additional depreciation"), the section 1231 netting, the
5-year lookback with persisted history (V175-era `out_section_1231_recapture`), the unrecaptured section 1250 gain, Part
IV with routing back to Schedule C / F / E, Schedule 1 line 4 and Schedule D line 11 all work, and the preview is filled
from the finished entries (`F4797F`).

**9 differences from the IRS rules** (D-4797-1 … D-4797-9). The ones that change tax silently:

- **D-4797-1 (high):** the partner's / S shareholder's **net section 1231 gain or loss** (K-1 1065 box 10, K-1 1120-S
  box 9) is saved but never read — it never reaches Form 4797 Part I, so it is left out of income.
- **D-4797-2 (medium):** on a **joint return** the section 1231 netting is done **per spouse**, not per return: one
  spouse's net gain goes to Schedule D while the other's net loss is an ordinary loss.
- **D-4797-3 (medium):** the lookback (line 8) knows only losses **stored by this app** for 2020–2024; there is no
  question for losses from returns filed elsewhere.
- **D-4797-4 (medium):** on **married filing separately** returns the lookback recharacterization is never applied.

The rest are rare unsupported cases (livestock holding periods, investment depreciable property, sections 1252–1255,
section 121 / 1244 / 475(f) / QOF) and presentation or advice problems. Person attribution: the intake is a taxpayer /
spouse personal form, so the D-1a-1 root cause (a dependent's statement on the parent's return) does not apply to it;
for the API-only statement path it is **unverified** (no screen can create such an entry).

## 4. How it is computed

Assembly (`TRCS:3141-3159`): typed statement entries → `Form6252Compute.withForm4797` (installment property) →
`Form4797SalesCompute.withSales` (intake) → `Form8824Compute.withForm4797` (business exchanges) →
`Form4684SectionB.withForm4797` (casualties). Then `withDerivedForm4797PartIv` (`TRCS:1870-1971`) adds derived Part IV
entries, `computeForm4797Part3Recapture` runs (`TRCS:3182-3185`), Schedule 1 line 4 is filled (`TRCS:3196-3221`), the
lookback runs (`TRCS:3226-3234`), and Schedule D reads line 9 and the unrecaptured amounts later (`TRCS:25346-25362`).

Steps, mirroring `new_lines\forms\4797.md` §6:

1. **Intake → Part III property** (`F4797S:42-120`). Only when `hasBusinessPropertySale` is Yes. Each sale becomes
   property A of its own entry: line 19 description and dates ("INHERITED" in (b) when inherited), line 20 = price,
   line 21 = cost + expenses, line 22 = depreciation (0 for land), line 26a = typed additional depreciation (0 when
   blank) **only for `building`**, AMT depreciation for line 2k. Blocking: no / non-2025 date sold
   (`FORM_4797_SALE_DATE_SOLD`), no date acquired and not inherited (`FORM_4797_SALE_DATE_ACQUIRED`), no price
   (`FORM_4797_SALE_PRICE_MISSING`); the same property on Installment sales blocks (`FORM_4797_SALE_ALSO_INSTALLMENT_SALE`);
   a typed statement property with the same description and dates wins (`F4797S:66`, `:127-144`). `usedFor` ≠
   `schedule_c` only marks the recapture as "not Schedule C QBI" (`F4797S:105`) — "Other" is otherwise treated like a
   business (D-4797-6).
2. **Line 1a / 1b / 1c.** Not figured or printed (D-4797-5); 1b / 1c not supported (D-4797-8).
3. **Lines 23–24** per slot A–D: adjusted basis = 21 − 22; gain = 20 − 23 (`TRCS:2095-2096`, written `:2122-2123`).
4. **Holding period** — `isLongTermHold`: "INHERITED" → long; else sold − 1 year is after acquired; a missing date →
   short (`TRCS:25545-25555`). One year for every property type, livestock included (D-4797-7).
5. **Held one year or less** → whole gain or loss ordinary (Part II line 10), except an installment property, which
   takes only min(gain, depreciation) now (`TRCS:2133-2137`).
6. **Section 1250** (line 26a present): 26g = 26b = min(gain, 26a) (applicable percentage 100%; 26c–26f not figured);
   the residual gain − 26g joins the section 1231 net (not for an installment property); unrecaptured = max(0,
   min(gain, depreciation) − 26g), or this year's installment share (`TRCS:2138-2162`). A loss → section 1231 loss.
7. **Section 1245** (no line 26a): 25a = depreciation, 25b = min(gain, depreciation) → ordinary; the rest → section 1231
   (`TRCS:2163-2181`). A building typed as "equipment" (or a typed statement building without 26a) raises the
   description-based advisory `FORM_4797_POSSIBLE_SECTION_1250_REAL_PROPERTY` (`TRCS:1787-1807`, `:3488-3500`) — whose
   advice is wrong (D-4797-9).
8. **Sections 1252 / 1254 / 1255** (lines 27–29): no inputs, not figured (D-4797-8).
9. **Lines 3, 4, 5, 14, 16** — from the synthesized entries: an earlier-year installment sale (line 4 / 10, Step 3
   unrecaptured share, `TRCS:2211-2224`), a like-kind exchange or a casualty (`Form4797Synthesized.amounts`,
   `TRCS:2225-2230`). Line 15 (Form 6252 line 25 / 36) is never filled — **D-6252-1**.
10. **Part IV** — typed lines 33 / 34 or derived ones (`withDerivedForm4797PartIv`, `TRCS:1870-1971`; details in
    `4562.md`): line 35 = max(0, 33 − 34) per column (`TRCS:2200-2209`). A derived recapture whose activity is on the
    return goes back to that Schedule C line 6 / Schedule F line 8 / Schedule E line 3 (B80, `TRCS:2244-2250`);
    otherwise Schedule C (single business) or Schedule 1 line 4. Basis-increase advisory `FORM_4797_PART_IV_BASIS_INCREASE`.
11. **Ordinary split by person** (`TRCS:2241-2262`): per entry, recapture + 26g + short-term → `qbiRecapture` (a
    Schedule C sale) or `nonScheduleC`; Part IV → `seRecapture`.
12. **Section 1231 netting — per owner** (`TRCS:2265-2277`, `consolidateSection1231` `TRCS:1814-1827`): each person's
    entries are netted into the first ("carrier") entry: line 7 = net, line 9 = max(0, net). A net **loss** is added to
    that person's ordinary amount (Schedule 1 line 4). On a joint return the taxpayer and the spouse are netted
    separately — **D-4797-2**.
13. **Schedule 1 line 4** (`TRCS:3196-3221`): taxpayer / spouse ordinary amounts added to `otherGainsLossesLine4`
    (marked as figured, so the typed-amount advisory ignores them, `F4797S:169-183`).
14. **Lines 8–9, lookback** (`computeSection1231Lookback`, `TRCS:1689-1722`): line 7 = Σ line 7 of all entries (both
    spouses); line 8 = min(line 7, `nonrecapturedPriorYear1231Losses`) where the latter = Σ net losses − Σ recaptured of
    the app's own **primary** returns for 2020–2024 (`TRCS:1662-1680`) — D-4797-3. `section1231RoutingDelta`
    (`TRCS:1729-1752`) moves line 8 (less any typed line 8) from Schedule D to the taxpayer's Schedule 1 line 4 by
    lowering the **first** entry's line 9 (D-4797-2), and returns 0 on any scoped compute — MFS legs (D-4797-4). The
    unrecaptured section 1250 amounts are then capped at the new line 9 (`ISL:45-71`).
15. **Schedule D line 11** — positive line 9 of each entry, per person (`TRCS:25346-25356`); Schedule D is produced for
    a Form 4797 gain even without the Capital gain/loss screening (`TRCS:24752-24762`, `:24083-24089`).
16. **Unrecaptured section 1250 gain** — per entry, `InstallmentSaleLink.unrecaptured` (`ISL:80-101`) → Schedule D
    worksheet → line 19 (`TRCS:25358-25361`). The cap at Form 4797 line 7 runs only with a lookback — **D-sch-d-1**.
17. **Form 6251 line 2k** — Σ (AMT depreciation − regular depreciation) of disposed property (`TRCS:2091-2094`, used
    `:4175`).
18. **Preview values** (`F4797F:35-176`, called `TRCS:7704`): long-term gain with depreciation (or a building) → Part
    III (first four; advisory `FORM_4797_MORE_THAN_FOUR_PROPERTIES`); long-term loss and land → line 2; short-term →
    line 10; line 32 excludes installment property; line 6 = 32 − casualty part; lines 3 / 4 / 5 / 14 / 16 from the
    synthesized entries; line 7 = 2 + 3 + 4 + 5 + 6; line 8 = the **recharacterized** amount (D-4797-5); line 12 =
    min(8, 7); line 11 = a negative line 7; line 13 = line 31; lines 17 = 18b; Part IV 33–35. Line 1a, 15, 18a never
    printed. The preview is built from the entries of the whole return, so on a joint return it shows the combined
    line 7 even though the tax used the per-spouse nets (D-4797-2).
19. **Rounding** — `roundMoney` on each line (`putMoneyString`, `TRCS:1829-1831`).

## 9. Limits and out of scope

- Livestock, timber, coal / iron ore, unharvested crops, section 126 property: no property types beyond building /
  equipment / land.
- Partners' / S shareholders' section 179 property dispositions (the i4797 worksheet) are not asked.
- Building and land sold together: the filer must split them into two sales (the form does not allocate by FMV).
- Pre-1976 additional depreciation (26d / 26e), section 291 (corporations) and low-income-housing percentages (26b) are
  not asked.
- The typed Form 4797 statement path (PDF-slot keys) is API-only and kept for unit tests and compatibility.
- The lookback history is only what this app has stored (D-4797-3); Form 4797 itself has no carryforward field.
