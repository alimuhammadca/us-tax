# Form 8853 — how the app does it

IRS rules: `C:\us-tax\new_lines\forms\8853.md`. Flowchart: `C:\us-tax\new_flowcharts\forms\8853.md`.
Paths are relative to `C:\us-tax`. `TRCS` = `us-tax-be/src/main/java/com/ustax/microservices/TaxReturnComputeService.java`.
`MSA-UI` = `us-tax-ui/src/app/forms/form-msa-ltc.component.ts`.

---

## 1. Status

Form 8853 is computed per person (taxpayer, spouse) from the "Archer MSA / LTC (Form 8853)" form, the person's Forms
1099-SA (box 5 "Archer MSA" or "MA MSA", matched by recipient TIN), Forms 1099-LTC (box 3 "Per diem" / "Reimbursed
amount", matched by policyholder TIN) and W-2 box 12 code R. Line 5 goes to Schedule 1 line 23 **only if nothing is
typed there**; lines 8 + 12 + 26 go to Schedule 1 line 8e and lines 9b / 13b to Schedule 2 lines 17e / 17f, typed values
winning. Form 5329 Part VI (6% on excess Archer contributions) is computed. A blocking flag stops the return when
per-diem LTC benefits are on file and line 18 is unanswered.

**8 differences from the IRS rules** (D-8853-1 … D-8853-8), plus the already-recorded D-8-13 (the line 8e advisory
says the app does not compute Form 8853) and D-10-10 (a typed Schedule 1 line 23 wins over Form 8853 line 5, uncapped).
The most serious: on a married-filing-separately return the other spouse's 20% / 50% MSA taxes are added to this
return's Schedule 2 (D-8853-1); the Form 8853 preview prints blank, so the required form is not produced (D-8853-7).

## 4. How it is computed

Methods: wiring `TRCS:2958-2980`; wrapper `computeForm8853` `TRCS:10497-10588`; pure lines
`computeForm8853FromInputs` `TRCS:9827-9929`; excess `applyArcherMsaExcessContributions` `TRCS:10608-10656`; readers
`sum1099SaDistributionsByFlag` `TRCS:10659-10671`, `sum1099LtcBox1` `TRCS:10685-10700`; injections
`injectMsaDeduction` `TRCS:10703-10711`, `injectMsaLtcOtherIncome` `TRCS:10714-10724`, `injectMsaSchedule2Taxes`
`TRCS:10727-10745`; Form 5329 Part VI `TRCS:5356-5367`.

Steps, mirroring `new_lines\forms\8853.md` section 6:

1. **Gate.** Nothing unless `hasMsaLtcActivity` is Yes (`TRCS:10503`).
2. **Line 1.** Typed, else the person's W-2 box 12 code R (SSN-matched) (`TRCS:10515-10518`). Only the person's own
   line 1 blocks the person's deduction; a family-coverage spouse's employer contribution does not (D-8853-5).
3. **Line 3.** Typed override (not on the UI), else 65% / 75% × the annual deductible, prorated by months only when
   "all 12 months" is No — and since neither question is on the UI, months default to 12 and "all year" to false, so
   the full annual percentage is always used (`TRCS:9844-9859`, `:10506`, `:10562-10563`). No MFS 37.5%, no
   deductible-range check, no lowest-deductible rule for two family plans (D-8853-4).
4. **Line 4.** Typed compensation; blank counts as 0, which makes line 5 = 0 (`TRCS:9860-9861`).
5. **Line 5.** Smallest of 2, 3, 4; 0 when line 1 > 0 (`TRCS:9861-9867`). A prior-year excess absorbed by unused room is
   added when no employer contributed (`TRCS:10629-10634`). Put into Schedule 1 line 23 **only if** the user typed
   nothing there (`TRCS:10703-10711`; D-10-10).
6. **Excess / Form 5329 Part VI.** Own excess (2 − 5) + employer excess (1 − min(3, 4)), less withdrawn; prior excess;
   6% of the smaller of the total and the year-end value (`TRCS:10608-10641`); spouse excluded on MFS
   (`TRCS:5358-5360`). Employer excess is not added to income — the advisory says it is income "if your W-2 did not
   include them in box 1" (`TRCS:10652-10653`).
7. **Line 6a.** Box 1 of the person's 1099-SAs with box 5 "Archer MSA" and TIN = SSN (`TRCS:10508`, `:10659-10671`).
   Line 6b typed; 6c, 7 (typed), 8 as on the form (`TRCS:9875-9879`).
8. **Line 9b.** 0 if the exception box is Yes, else 20% × line 8 (`TRCS:9880-9881`) — all or nothing; no partial
   exception and no automatic age-65 / 1099-SA code 3 / 4 exception (D-8853-2).
9. **Section B.** Line 10 = box 1 of "MA MSA" 1099-SAs (`TRCS:10509`); line 12 = 10 − 11; line 13b = 0 if the exception
   box is Yes, else 50% × line 12 (`TRCS:9891-9895`). The Additional 50% Tax Worksheet (December 31, 2024 value, 60% of
   the deductible) is not applied (D-8853-3).
10. **Line 17.** Box 1 of 1099-LTCs with box 3 "Per diem" whose policyholder TIN matches — or that have no TIN, which
    then count for **each** spouse (`TRCS:10510`, `:10685-10700`) (D-8853-8).
11. **Line 18.** Typed; if line 17 > 0 and line 18 is blank, the blocking flag
    `FORM_8853_LTC_QUALIFIED_CONTRACT_PORTION_MISSING_*` (`TRCS:10533-10546`).
12. **Line 19.** Typed only (box 2 not read). **Line 20** = 18 + 19 (`TRCS:9903-9906`).
13. **Lines 21–25.** Line 21 = $420 × typed days (`ReferenceData.LTC_PER_DIEM_LIMIT`,
    `us-tax-be/src/main/java/com/ustax/microservices/ReferenceData.java:651`); 22 typed; 23 larger; 24 typed, else box 1
    of the person's "Reimbursed amount" 1099-LTCs (TIN-less ones for each spouse, D-8853-8) (`TRCS:10553-10557`); 25
    (`TRCS:9907-9912`). One insured and one LTC period per person; line 15 is never asked (D-8853-6).
14. **Line 26** = max(0, 20 − 25) (`TRCS:9913`).
15. **Routing.** 8 + 12 + 26 → `otherIncomeForm88538e` unless typed / imported (`TRCS:10714-10724`); spouse dropped on
    MFS by the other-income step (`TRCS:32054`). Line 23 spouse dropped on MFS (`TRCS:32782`). Lines 9b and 13b summed
    for taxpayer **and spouse with no MFS guard** → Schedule 2 lines 17e / 17f unless typed (`TRCS:2980`,
    `:10727-10745`, read `:43253-43254`) (D-8853-1).
16. **Rounding.** `roundMoney` (half-up, whole dollars) per line.

## 8. Compared with the IRS rules

| # | IRS rule (source) | What the app does | Result |
|---|---|---|---|
| 1 | Line 1 = W-2 box 12 code R; any employer contribution → line 5 = 0 (`i8853.pdf p. 3`) | Typed or code R; line 5 = 0 when own line 1 > 0 (`TRCS:9865-9867`) | Match |
| 2 | Family coverage + employer contribution to either spouse's MSA → neither spouse may deduct (`i8853.pdf p. 3`) | Only the person's own line 1 is checked | **Deviation D-8853-5** (low; over-deduction) |
| 3 | Line 3: month by month, 65% / 75% of a deductible within the 2025 range; Medicare / ineligible months $0; MFS family 37.5%; two family plans → lowest deductible (`i8853.pdf p. 2-5`) | Full-year 65% / 75% of the typed deductible; months and override not on the UI; no range check; no MFS or two-plan rule (`TRCS:9844-9859`) | **Not supported D-8853-4** (silent over-deduction for part-year or MFS; low — Archer MSAs are a closed program) |
| 4 | Line 5 = smallest of 2, 3, 4 → Schedule 1 line 23 (`f8853.pdf p. 1`) | As stated; injected only if line 23 is not typed | Match; typed-wins is D-10-10 |
| 5 | Excess contributions → Form 5329; excess employer contributions not in W-2 box 1 → other income (`i8853.pdf p. 5`) | Form 5329 Part VI computed; employer excess only mentioned in the advisory, not added to income | Match (excise); employer excess: advisory only, not computed (low; same gap as D-8889-2) |
| 6 | Line 6a = 1099-SA box 1, both spouses' Archer MSAs (`i8853.pdf p. 5`) | Per person, box 5 "Archer MSA", TIN = SSN; both spouses' forms on MFJ | Match |
| 7 | Line 9b = 20% of the part of line 8 not after death / disability / age 65 (`i8853.pdf p. 6`, Examples 1–3) | Checkbox exempts the whole line 8; otherwise 20% of all of it; no age or 1099-SA code check | **Deviation D-8853-2** (over-tax if the box is left No for a 65+ holder; under-tax if checked for a mixed year; low–medium) |
| 8 | Line 13b: 50% unless death / disability; Additional 50% Tax Worksheet for a holder with an MA MSA on 12/31/2024 (`i8853.pdf p. 7`) | 50% × line 12 or 0 (`TRCS:9894-9895`) | **Not supported D-8853-3** (overstates the 50% tax; low) |
| 9 | Line 17 = box 1 of per-diem 1099-LTCs for the insured (`f8853.pdf p. 2`) | Per-diem 1099-LTCs of the person (by policyholder TIN; TIN-less ones counted for each spouse) | Match; TIN-less: **Deviation D-8853-8** |
| 10 | Line 18 is the qualified-contract part (`f8853.pdf p. 2`) | Typed; blocker when missing | Match |
| 11 | Line 19: chronically-ill accelerated death benefits, "generally shown in box 2 of Form 1099-LTC" (`i8853.pdf p. 8`) | Typed only; box 2 not read | Match (needs the user's judgment of chronic vs terminal; no flag) |
| 12 | Line 21 = $420 × days; separate Section C per LTC period and per insured; line 15 Yes → multiple-payee allocation (`i8853.pdf p. 8-10`) | One insured, one period per person; line 15 never asked; full limit always given to the filer | **Not supported D-8853-6** (silent; can under-state income when others also received per-diem payments; low) |
| 13 | Line 24 = reimbursements (1099-LTC box 3 "Reimbursed amount") (`i8853.pdf p. 9`) | Typed, else reimbursement 1099-LTCs (TIN-less counted for each spouse) | Match; TIN-less: D-8853-8 |
| 14 | Line 26 = max(0, 20 − 25) → Schedule 1 line 8e (`f8853.pdf p. 2`) | As stated | Match |
| 15 | Schedule 1 line 8e = lines 8 + 12 + 26 (`i1040gi_ty2025.pdf p. 91`) | As stated; typed wins | Match |
| 16 | Separate returns: each spouse's own additional taxes | 9b / 13b of taxpayer and spouse summed with no MFS guard; on a primary MFS return the spouse's MSA form is kept (`multireturn/MfsFormScoper.java:780-791`), so the spouse's tax is added (`TRCS:2980`, `:10727-10745`) — Form 8889 has this guard (`TRCS:2953-2956`) | **Deviation D-8853-1** (tax overstated on MFS; medium) |
| 17 | File Form 8853 with the return (`i8853.pdf p. 1`) | Computed and stored; preview blank; header empty; the line 8e / 23 advisories say the form is not computed (D-8-13) | **Not supported D-8853-7** (filed form not produced; medium) |
| 18 | Death of holder, statement / controlling forms, deemed distributions (`i8853.pdf p. 2, p. 7`) | Not modelled | Out of scope (see §9) |

## 9. Limits and out of scope

- **Death of the account holder** (FMV at death on 6a / 10), "statement" and controlling forms, prohibited transactions
  and loan security — typed amounts only.
- **Non-qualified LTC contracts** — taxable part must be typed on Schedule 1 line 8e.
- **Pre-August-1996 contract reimbursements** — the user decides what to type on line 24.
- **Form 5498-SA** — not read.
