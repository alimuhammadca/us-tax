# Form 8949 — how the app does it

IRS rules: `C:\us-tax\new_lines\forms\8949.md`. Flowchart: `C:\us-tax\new_flowcharts\forms\8949.md`.
Paths are relative to `C:\us-tax`. `TRCS` = `us-tax-be/src/main/java/com/ustax/microservices/TaxReturnComputeService.java`.
Which statements belong to the return (person matching) and Exception 1 are in `new_knowledge\7a.md` (D-7a-1 …
D-7a-10, referenced here); the Schedule D side is in `new_knowledge\forms\schedule-d.md`.

## 1. Status

Form 8949 is built inside `computeCapitalGainLoss` (`TRCS:23515`). Rows come from Form 1099-B (boxes A, B, D, E),
Form 1099-DA (boxes G, H, J, K), Form 1099-S property rows (box C / F), hand-entered rows (any box A–L, any one code),
nonbusiness bad debt (box C), bargain sales to charity, and employer-stock (NUA) splits. A 1099-B wash-sale amount
becomes code W. Rows in box A / D / G / J with no wash sale and no QOF box are not listed — they are summed on
Schedule D line 1a / 8a (Exception 1 of the Form 8949 instructions). The rest are grouped by box onto pages of 11 rows
and totalled into Schedule D lines 1b–3 / 8b–10. Form 8949 is attached whenever Schedule D is required and at least
one row (or a QOF indicator) exists (`TRCS:24108`).

**8 differences from the IRS rules** (D-8949-1 … D-8949-8). The most serious, all silent:

- **D-8949-1:** a 1099-B or 1099-DA whose short / long box is blank and whose dates are missing or not dates
  ("VARIOUS") is **dropped** — no row, no flag. For 2025 digital assets this is the normal case: every digital asset
  acquired before 2026 is noncovered, and the 1099-DA may leave the date acquired and box 6 blank.
- **D-8949-2:** 1099-B box 7 / 1099-DA box 5 "loss not allowed" is stored but never read — the loss is deducted.
- **D-8949-3:** no column (f) / (g) adjustment can be made to a broker-reported transaction (codes B, D, E, L, N, O,
  T, a corrected W, …); the screen allows hand rows only for sales "not on any broker statement".
- **D-8949-4:** a blank basis on a 1099-B / 1099-DA is taken as $0 with no prompt — the whole proceeds become gain.
- **D-8949-5:** a 1099-S property row that matches no 1099-S statement is put on Form 8949 with $0 proceeds.

Also on Form 8949 rows: D-7a-1 (a dependent's 1099-B / 1099-DA), D-7a-5 (Ordinary, collectibles and market-discount
boxes not read, so no code C / D), D-7a-6 (home-sale $500,000 cap), D-7a-8 (a fully excluded home sale without a
1099-S still listed).

## 4. How it is computed

Methods (all in `TRCS`): `buildCapitalTransactionsFrom1099B` `:24900-24936`; `splitNuaStockSales` `:24951-25023`;
`buildCapitalTransactionsFrom1099Da` `:25029-25065`; `buildManualTransactions` `:25067-25160`;
`addNonbusinessBadDebtTransaction` `:25564-25596`; `derive1099STransactionsAndEmitFlag` `:25619-25666`,
`build1099SDerivedTransaction` `:25728-25790`, `buildPrincipalResidenceTransaction` `:25796-25915`;
`derive1099BBox` `:26172-26209`; `derive1099DaBox` `:26211-26235`; `isDirectScheduleDBox` `:26168`;
`belongsToEitherCapitalPersonByKey` `:26252-26278`; `buildForm8949Pages` `:26047-26064`; `buildForm8949Page`
`:26066-26106`; `computeGainOrLoss` `:26158-26166`; record `CapitalTransactionRecord` `:55227-55239`.

Steps, mirroring `new_lines\forms\8949.md` §6:

1. **Which statements.** 1099-B / 1099-DA of the whole account, kept when the recipient TIN is the taxpayer's or the
   spouse's, or (any other or blank TIN) when the taxpayer or spouse answered Yes to capital activity; on MFS the
   other spouse's TIN is excluded first (`TRCS:26252-26278`, D-7a-1).
2. **Box (Part and column).**
   - 1099-B: the "Applicable checkbox on Form 8949" if it is a letter A–L; else box 2 short / long with box 12 → A / B
     or D / E; with box 2 blank, "INHERITED" in date acquired → long-term, else long-term if the sale date minus one
     year is after the acquisition date (`TRCS:26172-26209`). If none of these gives a term, **no row** (D-8949-1).
   - 1099-DA: box 6 short / long with box 2 → G / H or J / K; with box 6 blank, the same date test; else **no row**
     (`TRCS:26211-26235`, D-8949-1). The 1099-DA "Applicable checkbox" is not read.
   - Hand rows: the box the user picked; a code-Q row is checked against the 5-year / 3-year holding rule; a section
     1259 constructive-sale row has its box corrected to C / F from the dates (`TRCS:25090-25145`). No other check of
     box against dates or term (D-8949-7).
   - 1099-S rows: C or F from the dates (`TRCS:25773`); bad debt: C (`TRCS:25580`); NUA: the NUA part moves to D / E /
     F (`TRCS:24991-25016`).
3. **Columns (a)–(e).** As listed in §2. A blank basis is carried as null and treated as 0 in column (h)
   (`computeGainOrLoss` `TRCS:26158-26166`) — no prompt for a noncovered security's basis (D-8949-4). 1099-S rows: (d)
   = 1099-S gross proceeds, or **0 when the row matches no statement** (`TRCS:25756-25758`, D-8949-5); (e) = basis +
   improvements **+ selling expenses** (`TRCS:25761-25763`, D-8949-6).
4. **Columns (f) and (g).**
   - 1099-B / 1099-DA: code W with the box 1g / 1i amount when non-zero (`TRCS:24918-24930`, `:25051-25063`); nothing
     else — no code B / C / D / E / L / N / O / T on a broker row (D-8949-2, D-8949-3, D-7a-5).
   - 1099-S: principal residence gain → code H, (g) = −excluded gain; loss on a principal residence or second home →
     code L, (g) = +loss; investment property → no code (`TRCS:25786-25915`).
   - Hand rows: one code from the dropdown and the amount as typed (sign not checked); a QSB-stock description with
     code X → advisory (`TRCS:25078-25088`).
5. **Column (h).** (d) − (e) + (g) on cents (`TRCS:26158-26166`), then rounded per row (`TRCS:26087-26093`).
6. **Exception 1 (not listed).** A 1099-B / 1099-DA row in box A / D / G / J with no wash-sale amount and no QOF box
   is `directScheduleDEligible` and goes to Schedule D line 1a / 8a instead of a page (`TRCS:24931`, `:25064`). Hand
   rows and 1099-S rows are always listed.
7. **Pages.** Rows are grouped in box order A, B, C, G, H, I, D, E, F, J, K, L and cut into pages of 11
   (`FORM8949_ROWS_PER_PAGE`, `TRCS:145`; `TRCS:26047-26064`). Each page holds part, term, box, its Schedule D line
   reference and totals; totals are rounded from the cent sums (`TRCS:26097-26105`) (D-8949-8). Code-Z pages are not
   put first.
8. **Required.** `form8949Required = scheduleDRequired && (pages exist || QOF indicator)` (`TRCS:24108`); the
   `Form8949` object holds the pages (`TRCS:24181-24189`).
9. **QOF.** A code Y / Z hand row or a 1099-B / 1099-DA QOF box makes Form 8997 required (`TRCS:23400-23440`; blocking
   `FORM_8997_REQUIRED_MANUAL_FILL` unless acknowledged); code-Z rows are checked for the 180-day window and for
   deferring more than the gain (`TRCS:23451-23510`, called `:3816`).

## 9. Limits and out of scope

- Exception 2 statements, Form 8453 mailing and the "Available upon request" special provision are not produced.
- The basis-adjustment, accrued-market-discount and contingent-payment-debt worksheets are not implemented
  (D-8949-3, D-7a-5).
- 1099-DA optional reporting (box 11a–c stablecoins / NFTs aggregate) is not distinguished.
- Form 1099-K personal-property sales are not turned into Form 8949 rows here.
