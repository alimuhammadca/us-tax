# Form 1040 line 4c — IRA distributions, "Check if" boxes

Tax year 2025. What the IRS requires. How the app does it: `C:\us-tax\new_knowledge\4c.md`. Picture:
`C:\us-tax\new_flowcharts\4c.md`. Amounts: lines 4a / 4b (`new_lines\4a.md`, `new_lines\4b.md`).

---

## 1. At a glance

Line 4c holds three checkboxes and one write-in space that explain why line 4b is smaller than line 4a. It carries no
amount and adds nothing to income.

```text
box 1 "Rollover"  ← Exception 1 (part or all of an IRA distribution rolled over)
box 2 "QCD"       ← Exception 3 (qualified charitable distribution)
box 3 + text      ← Exception 4 → "HFD"; or any word / code another publication or instruction says to write
                    next to line 4b (for example "SIE" for the one-time QCD to a split-interest entity)
Exception 2 (Form 8606) has no box.
More than one exception → check a box for each and attach a statement of the amount of each
                          (not needed when only Exception 2 and one other exception apply).
```

## 2. The IRS wording

**Form 1040 (2025):** "c Check if (see instructions) . . . 1 Rollover   2 QCD   3 ____" (`C:\us-tax\docs\IRS-Forms\
f1040.pdf p. 1`).

**2025 Instructions for Form 1040, Line 4c** (`i1040gi_ty2025.pdf p. 28`):

> "If Exception 1 applies to you, check box 1 on line 4c. If Exception 3 applies to you, check box 2 on line 4c. If
> Exception 4 applies to you, check box 3 on line 4c and enter "HFD" in the entry space next to box 3."

> "If another publication or instruction tells you to write a word or code next to line 4b, check box 3 on line 4c and
> enter that word or code on the entry space next to box 3."

> "If more than one exception applies, check a box for each exception and include a statement showing the amount of
> each exception, for example, "Line 4b – $1,000 Rollover and $500 HFD." You don't need to attach a statement if only
> Exception 2 and one other exception apply."

Exceptions 1, 3 and 4 also tell you to check the box (`i1040gi_ty2025.pdf p. 27`: "Also check box 1 on line 4c";
"Check box 2 on line 4c"; "Check box 3 on line 4c and enter "HFD" in the entry space next to box 3").

**Publication 590-B (2025)**, one-time QCD to a split-interest entity (`p590b.pdf p. 14`): "If you make the one-time
election to make a QCD to a split-interest entity (SIE), you must attach a statement to your tax return. Check box 3 on
line 4c and enter "SIE" in the entry space."

## 3. What each box means

| Box | Checked when | Source |
|---|---|---|
| 1 Rollover | Part or all of an IRA distribution was rolled over — Roth IRA to Roth IRA, or a traditional / SEP / SIMPLE IRA to a qualified plan or another non-Roth IRA (includes a direct payment from an IRA to an employer plan, 1099-R code G) | `i1040gi_ty2025.pdf p. 27`; `i1099r--2025.pdf p. 13` |
| 2 QCD | Part or all is a qualified charitable distribution | `i1040gi_ty2025.pdf p. 27` |
| 3 + text | "HFD" for an HSA funding distribution; "SIE" for the one-time QCD to a split-interest entity; any other word or code an IRS publication or instruction requires next to line 4b | `i1040gi_ty2025.pdf p. 28`; `p590b.pdf p. 14` |
| (none) | Exception 2 (Form 8606 cases) — Form 8606 itself is the explanation | `i1040gi_ty2025.pdf p. 27–28` |

## 4. Multiple exceptions and the statement

- Count the exceptions that apply on the return: 1, 2, 3, 4 (and any other box-3 code).
- One exception → no statement.
- Exception 2 plus exactly one other → no statement.
- Any other combination of two or more → check each box and attach a statement giving the amount of each exception.
- Separate statements are also required by the exceptions themselves: a rollover into a qualified plan or completed in
  2026 (`i1040gi_ty2025.pdf p. 27`) and the SIE election (`p590b.pdf p. 14`).

## 5. Married filing jointly / separately

On a joint return line 4c describes the combined lines 4a / 4b, so a box is checked if the exception applies to
either spouse. On a separate return only your own distributions count.

## 6. Where it goes next

Nowhere in the arithmetic. It is a disclosure that explains the 4a − 4b difference to the IRS.

## 7. Worked example

Chris Example (000-00-0031, age 75, single) rolled over $5,000 of a $30,000 IRA distribution and sent $10,000 to a
charity as a QCD. Line 4a $30,000; line 4b $15,000; line 4c box 1 and box 2 checked. Two exceptions other than
Exception 2 apply, so Chris attaches "Line 4b – $5,000 Rollover and $10,000 QCD."
