# Form 1098-T — Tuition Statement

Statement form id `1098-t`. Paths are relative to `C:\us-tax`. `TRCS` =
`us-tax-be/src/main/java/com/ustax/microservices/TaxReturnComputeService.java`. There is no `new_knowledge` file for
Form 8863 yet; the Form 8863 code paths cited here were read for this file.

---

## 1. What this statement is

An eligible educational institution sends Form 1098-T to each enrolled student for whom a reportable transaction was
made; an insurer that reimbursed or refunded qualified tuition also files one (`i1098et--2025.pdf` p. 2, "Specific
Instructions for Form 1098-T"). Form version used: **Form 1098-T (2025)**, Copy B (`docs/IRS-Forms/f1098t.pdf` p. 3).
The form says it "must be used to complete Form 8863 to claim education credits" (p. 3).

IRS instructions used:

- Student: "Instructions for Student" — `docs/IRS-Forms/f1098t.pdf` p. 4 (boxes 1-10).
- Filer: `i1098et--2025.pdf` p. 4 (boxes 1-10).
- Where it goes: `i8863_2025.pdf` p. 1 ("Form 1098-T requirement … the law requires a taxpayer (or a dependent) to have
  received Form 1098-T"; exceptions; "You may include qualified tuition and related expenses that are not reported on Form
  1098-T … You may not include expenses paid on the Form 1098-T that have been paid by qualified scholarships"), p. 4
  ("the amount in box 1 of Form 1098-T may be different from the amount you paid … use only the amounts you actually
  paid"), p. 6 (refunds; credit recapture), p. 8 (lines 22, 24, 25); `i1040gi_ty2025.pdf` p. 34 (Form 1040 line 16 box 3
  "ECR" — recapture of an education credit), p. 92 (Schedule 1 line 8r — scholarships "used for expenses other than
  tuition and course-related expenses"). Pub. 970 is not in `docs\books`.

**Whose statement it is.** The student in "STUDENT'S TIN", stored as `studentTIN`
(`us-tax-be/src/main/java/com/ustax/microservices/statement/Form1098TMapper.java:114`). The credit belongs to whoever
claims the student (the student or the parent who claims the student — `f1098t.pdf` p. 4: "You, or the person who can
claim you as a dependent, may be able to claim an education credit"). The wrong-person check uses `studentTIN`
(`StatementSsnRules.java:89`). The UI does not offer 1098-T on a dependent's tab
(`us-tax-ui/src/app/service/statement-selection.service.ts:135`), so a child's 1098-T is entered on a parent's tab.

**Storage.** Mapper `Form1098TMapper.java`; entity `Se1098T` / table `se_1098_t`. The list call returns every 1098-T of
the account for the year (`Form1098TMapper.java:69-80`). UI: `us-tax-ui/src/app/forms/form-1098-t.component.ts` —
`syncPdfToForm` (`:424-470`) copies every box into the model; every saved key has a mapper column and every mapper key
is on the screen. No UI box is lost. Upload extraction: Azure `prebuilt-tax.us.1098T` (`field-mappings.json`, key
`1098-t`), post-processed by `postProcess1098T` (`GenericFieldMapper.java:507-510`, `:7306`); Azure's
`AmountBilledForTuition` is mapped to `amountBilledForTuitionAmount`, which no mapper stores (box 2 has been reserved
since 2018, so nothing is lost).

**Is it used?** **No compute path reads any 1098-T box** (grep of every saved key across
`us-tax-be/src/main/java/com/ustax/microservices`, outside the mapper and extraction). Form 8863 is built entirely from
the **Education credits** personal form (`computeForm8863`, `TRCS:48686`): typed tuition paid
(`adjustedQualifiedEducationExpenses`) less typed tax-free assistance (`taxFreeEducationAssistanceReductionAmount`)
(`TRCS:48955-48957`), typed school name / EIN / "Did this school issue a 2025 Form 1098-T?" / "Was Box 7 on the 2024
1098-T checked?" (line 22), typed half-time (line 24). The UI shows a read-only "From the 1098-T you uploaded for this
student" card next to each student, matched by SSN, else by first + last name
(`us-tax-ui/src/app/forms/form-education-credits.component.html:445-475`,
`form-education-credits.component.ts:773-805`). So there is **no person filter to get wrong** — the statements do not reach
the return.

## 4. Questions the app asks with this statement

On the **Education credits** form (`education-credits`): "All Form 1098-T tuition statements uploaded (or none
received)?" (`confirmAllEducationSupportUploaded`, a save gate in the UI only); `receivedAny1098TForClaimedStudents`
with `usingAlternativeEnrollmentDocumentationForAnyStudent` — No + No → blocking `AOTC_1098T_NOT_RECEIVED_NO_ALTERNATIVE`
and no credit (`TRCS:48809-48815`, §25A(g)(8), matching `i8863_2025.pdf` p. 1); per student: tuition paid, tax-free
assistance, school name / address / EIN, "Did this school issue a 2025 Form 1098-T?", "Was Box 7 on the 2024 1098-T
checked?", half-time, credit type. Recapture: the line 16 tax form's ECR amount. Taxable scholarships: Other incomes
line 8r.

## 5. Differences from the IRS instructions

**D-1098-t-1 — the UI says the credit uses the 1098-T amounts; it does not.**
IRS: Form 8863 uses "only the amounts you actually paid (plus any amounts you're treated as having paid) in 2025",
which may differ from box 1 (`i8863_2025.pdf` p. 4) — so typed amounts are correct in principle.
Code: the help text of `confirmAllEducationSupportUploaded` says "Schools issue a Form 1098-T showing tuition paid. **The
credit calculation uses the amounts on those statements.**"
(`us-tax-ui/src/app/forms/form-education-credits.component.ts:361-363`), but no compute path reads a 1098-T box (see §1);
an uploaded 1098-T with no typed tuition gives no credit, and a box 5 scholarship not typed as tax-free assistance is not
subtracted.
Effect: **cosmetic / misleading** — the amounts are right only if the user retypes them; the echo card helps.
Severity: **low**.

Not given an id: box 4 / 6 / 10 prior-year adjustments and recapture are not derived from the statement (the user types
ECR, `TRCS:11836`); box 5 → line 8r is typed. The IRS treatments need facts the form does not carry (which year's credit,
how the scholarship was spent), so typed input is a reasonable design.
