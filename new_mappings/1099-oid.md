## 1. What this statement is

An issuer or broker sends Form 1099-OID to a holder of a debt instrument issued at a discount (OID of $10 or more for
the year), and for stated interest on such an instrument, Treasury inflation-protected securities, long-term CDs and
similar. OID is "taxable as interest over the life of the obligation" (`docs/IRS-Forms/f1099oid.pdf` p. 5). Form revision
used: **Form 1099-OID (Rev. January 2024)** (`docs/IRS-Forms/f1099oid.pdf` p. 1, title).

IRS instructions used:

- Recipient: "Instructions for Recipient" — `docs/IRS-Forms/f1099oid.pdf` p. 5 (boxes 1-5, covered securities,
  nominees) and p. 7 (boxes 6-11).
- Filer: `i1099int.pdf` p. 6-8 (Specific Instructions for Form 1099-OID; the INT/OID booklet, Rev. January 2024).
- Where each box goes: `i1040gi_ty2025.pdf` p. 25 (lines 2a / 2b), p. 39 (line 25b), p. 95 (Schedule 1 line 18);
  `i1040sb.pdf` p. 1-2 (Schedule B "OID Adjustment").

**Whose statement it is.** "RECIPIENT'S TIN", stored as `recipientTIN`; pre-filled from the active person tab on
creation (`us-tax-ui/src/app/service/statement-entry-state.service.ts:28-34`).

**Storage.** Mapper `us-tax-be/src/main/java/com/ustax/microservices/statement/Form1099OidMapper.java`; entity
`Se1099Oid` / table `se_1099_oid`, state rows `Se1099OidStateInfo` / `se_1099_oid_state_info`. Listing returns every
1099-OID of the account for the year (`Form1099OidMapper.java:74-83`). UI
`us-tax-ui/src/app/forms/form-1099-oid.component.ts` — `syncPdfToForm` (`:264-303`) saves every box; each saved key has a
mapper column (box 8 is sent as `oidOnUSTreasuryObligationsAmount` and stored in `oid_on_us_treasury_obligations_amount`,
`Form1099OidMapper.java:141`). No UI box is lost. The screen has no VOID box (Copy B has none); the model still carries
`void`. Upload extraction: Azure `prebuilt-tax.us.1099OID`, boxes mapped by number (`field-mappings.json` key
`1099-oid`; `GenericFieldMapper.java:751-754`, state rows lifted to `stateInfo` at `:4946-4950`).

**Person filter (the D-1a-1 question).** Loaded unsplit (`TRCS:3250`); each statement is kept for a person only when
`recipientTIN` is that person's SSN (`belongsToPerson`, `TRCS:19234-19236`, `:36021-36040`), so a dependent's 1099-OID is
**not** added to the parent's line 2a / 2b. It **is** dropped from Form 8814 too — Form 8814 reads only 1099-INT and
1099-DIV, so a child's OID reaches neither return unless typed (D-8814-3). Remaining person problems: blank TIN
(D-2a-3 / D-2b-2), box 3 (D-10-1), box 4 (D-1099-int-1), box 14 (D-1099-int-3). A TIN of no household member blocks
(`STATEMENT_DOES_NOT_BELONG_TO_FAMILY`, `TRCS:13891-13910`; `StatementSsnRules.java:64`).

## 4. Questions the app asks with this statement

On the Interest income form (`new_knowledge\2b.md` §2): "Portion of your 1099-OID "other periodic interest" that is
tax-exempt" (`taxExemptStatedInterestFrom1099OidBox2`) and "Override: taxable portion (advanced)"
(`taxablePortionFrom1099OidBox2Override`) — one amount per person, not per statement; a value above that person's
box 2 total blocks (`OID_BOX2_TAX_EXEMPT_EXCEEDS_TOTAL_*`, `OID_BOX2_OVERRIDE_EXCEEDS_TOTAL_*`, `TRCS:19298-19331`).
"Are you choosing to report bond market discount as interest each year…?" (`marketDiscountSection1278bElection`) adds
box 5. "Extra you paid above face value on an Original Issue Discount bond" and "Did your broker already lower the
interest amount…?" handle hand-entered acquisition premium. Line 18: income-adjustments form (`new_knowledge\10.md`).

## 5. Differences from the IRS instructions

Reused:

| Id | Box | Summary |
|---|---|---|
| D-2a-2 | 6, 10 | Premium is subtracted from box 1 + box 8 only: on a tax-exempt OID bond (box 2 / box 11) the premium is lost and line 2a is overstated; on a taxable bond box 10 nets against box 1 instead of box 2 |
| D-2a-3 / D-2b-2 | all amounts | Blank TIN counted on every return of the household |
| D-2a-4 / D-2b-7 | all | 1099-OID is not split for community property on MFS (`TRCS:3250`) |
| D-2b-6 | 1, 6, 10 | Premium netted silently; no Schedule B "OID Adjustment"; does not trigger Schedule B |
| D-10-1 | 3 | Penalty summed for the whole household |
| D-8814-3 | child's 1099-OID | Never read for Form 8814 and excluded from the parent's line 2b → the child's OID vanishes from both returns |
| D-1099-int-1 | 4 | Dependent's backup withholding credited on the parent's line 25b (defined in `1099-int.md`) |
| D-1099-int-3 | 14 | State withholding to Schedule A line 5a without a person filter except on MFS (defined in `1099-int.md`) |

New:

**D-1099-oid-1 — box 2 on a tax-exempt OID statement (box 11 filled) is taxed unless the user types the split.**
IRS: "If there is an amount in both boxes 2 and 11, the amount in box 2 is tax-exempt interest and is not included in
interest income on your tax return" (`docs/IRS-Forms/f1099oid.pdf` p. 5); "your tax-exempt stated interest should be
shown … for a tax-exempt OID bond, in box 2 of Form 1099-OID … Enter the total on line 2a" (`i1040gi_ty2025.pdf` p. 25).
Code: every statement's box 2 is pooled as taxable (`TRCS:19257`); only the hand-entered
`taxExemptStatedInterestFrom1099OidBox2` moves any of it to line 2a (`TRCS:19334-19340`). `taxExemptOidAmount` is read
only at `TRCS:19251` (added to 2a) and is not used to classify box 2; no advisory fires when a statement has both
boxes. Effect: **silent wrong amount** — line 2b overstated and line 2a understated by the tax-exempt stated interest
when the user does not type the split (the screen does not point to it). Severity: **medium** (tax-exempt OID bonds
reported on 1099-OID are uncommon, but the error is a direct overstatement of taxable income).
