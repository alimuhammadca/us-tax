## 1. What this statement is

The person responsible for closing a real estate sale (the settlement agent) reports the gross proceeds to the IRS and
gives the transferor (seller) Copy B. "To determine if you have to report the sale or exchange of your main home on
your tax return, see the Instructions for Schedule D (Form 1040). If the real estate was not your main home, report
the transaction on Form 4797, Form 6252, and/or the Schedule D … If box 4 is checked and you received or will receive
like-kind property, you must file Form 8824" (`f1099s.pdf p. 4`). A main-home sale for which a 1099-S was received
goes on Form 8949 even when all the gain is excluded (`i1040sd.pdf p. 2`); a loss on personal-use real estate with a
1099-S is reported with code L (`i1040sd.pdf p. 3`).

The 2025 form is **Form 1099-S (Rev. April 2025)** with boxes 1–6 (`docs\IRS-Forms\f1099s.pdf` Copy B p. 3,
Instructions for Transferor p. 4; filer instructions `i1099s--2025.pdf` p. 4). The app's screen follows the
**Rev. December 2026** layout (boxes 1, 2a–2c, 3, 4, 6, 7, 8a–8d — `i1099s.pdf` p. 4–5) — see D-1099-s-4. The table below
uses the 2025 box numbers and gives the screen number in brackets.

**Whose statement it is.** The transferor in "TRANSFEROR'S TIN" (`transferorTIN`). The mapper lists every 1099-S of the
account for the tax year (`MAP:65-75`). Compute **never reads `transferorTIN`**: each 1099-S is matched by address to a
"Property 1099-S Disposition" row on the taxpayer's or spouse's Capital gain/loss form, and any 1099-S with no matching
row blocks the return (`derive1099STransactionsAndEmitFlag` `TRCS:25619-25678`). The only TIN use is the household
belonging check (`StatementSsnRules.java:76`; blocking `STATEMENT_DOES_NOT_BELONG_TO_FAMILY`, `TRCS:13891-13915`).
So a dependent's 1099-S blocks the parent's return (already **D-7a-1**), and the other spouse's 1099-S blocks an MFS
return, and every household 1099-S blocks a dependent's own return (**D-1099-s-1**).

What the matched row produces (from the disposition row, not the statement): Form 8949 box C (short-term) or F
(long-term) by the row's dates (`TRCS:25773`); column (e) = basis + improvements **+ selling expenses**
(D-8949-6); main home → §121 exclusion, code H, $500,000 for any joint return (D-7a-6); second home loss → code L,
(g) = the loss (`TRCS:25791-25802`); investment property → full gain / loss; rental, business, farm, timber or other →
advisory `FORM_1099S_PROPERTY_TYPE_REQUIRES_FORM_4797`, no row (`TRCS:25740-25753`) (D-1099-s-5).

## 4. Questions the app asks with this statement

On the Capital gain/loss form (`capital-gain-loss-taxpayer` / `-spouse`, rows `property1099SDispositions[]`,
`us-tax-ui/src/app/forms/form-capital-gain-loss-taxpayer.component.ts:761`; read by `collectDispositions`
`TRCS:25680-25705`): "Property address or description" (match key), "Property type", date acquired, date sold, cost or
other basis, improvements, selling expenses, and for a main home the 2-of-5-years use, a §121 exclusion in the last 2
years, partial-exclusion reason / override, days used as main home, prior excluded sale date and nonqualified-use days.
The Business property sales form (Form 4797) is where rental / business real estate is computed; a 1099-S with the
same price triggers the advisory above. Flags: blocking `FORM_1099S_REAL_ESTATE_REPORTED` for each unmatched 1099-S
(`TRCS:25665-25677`); `CAPITAL_ANSWERED_NO_WITH_CAPITAL_DETAIL` (`CapitalScreeningCheck.java:19-34`). Nothing asks about
box 4 consideration or box 6.

## 5. Differences from the IRS instructions

Referenced: **D-7a-1** (a dependent's 1099-S blocks the parent's return), **D-7a-2** (the dependent's own Capital
gain/loss form is never read), **D-7a-6** ($500,000 cap for every joint return), **D-7a-8** (a home-sale row without
a 1099-S always produces a Form 8949 row), **D-8949-5** (row with no matching 1099-S gets $0 proceeds), **D-8949-6**
(selling expenses folded into column (e)).

New:

| ID | IRS rule | What the code does | Effect |
|---|---|---|---|
| **D-1099-s-1** | A 1099-S is reported on the return of its transferor (`f1099s.pdf p. 4`); on separate returns each spouse reports their own sales | `transferorTIN` is never read by compute; all household 1099-S are matched only against the taxpayer's and (not on MFS) the spouse's rows (`TRCS:3270`, `:23563`, `:25632-25661`).
