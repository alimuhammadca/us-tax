# Form W-2 (`w-2`) — every box and where it goes

Paths are relative to `C:\us-tax`. `TRCS` = `us-tax-be/src/main/java/com/ustax/microservices/TaxReturnComputeService.java`.
`UI-W2` = `us-tax-ui/src/app/forms/form-w-2.component.ts`. `MAP` = `us-tax-be/src/main/java/com/ustax/microservices/statement/W2Mapper.java`.
IRS text is cited from the page-marked copies of `C:\us-tax\docs\books\` (and the form copy `docs/IRS-Forms/fw2.pdf`, 2025).

## 1. What this statement is

Form W-2, Wage and Tax Statement, is sent by an employer to each employee (and to SSA) to report wages, tips and
other compensation and the income, social security and Medicare taxes withheld for calendar 2025
(`iw2w3--2025.pdf p. 4`). The employee uses Copy B / C; the "Notice to Employee" (`fw2.pdf p. 5`) and "Instructions for
Employee" (`fw2.pdf p. 7, p. 9`) say where each box goes; `i1040gi_ty2025.pdf` gives the Form 1040 lines.

**Whose statement it is.** Box a (employee's SSN), saved as `employeeSSN`. All W-2s of the household are stored under
one account (`MAP:85-96` lists every W-2 of the `uid` for the tax year — taxpayer's, spouse's and dependents'). A W-2
whose box a matches nobody in the household raises the **blocking** flag `STATEMENT_DOES_NOT_BELONG_TO_FAMILY`
(`TRCS:13891-13913`, rule `StatementSsnRules.java:53`); a W-2 with no box a is not checked. Compute filters by box a
only on married-filing-separately returns and on a dependent's own return (`scopedFilerSsn`) — on single, joint,
head-of-household and QSS returns a dependent's W-2 is read as if it were the filer's. This is **D-1a-1**
(`new_knowledge/1a.md`) and it reaches every box below that has no per-person filter of its own; the extra readers
found in this pass are recorded as **D-w-2-4**.

**Where it is stored.** Entity `SeW2` / table `se_w2`, children `se_w2_box12_entry` (box 12), `se_w2_box14_other`
(box 14), `se_w2_state_local_info` (boxes 15–20). Mapper `MAP:117-159` (parent), `:164-217` (children).

**What the user sees.** The W-2 screen always opens in the form-replica view (`_pdfView = true`, `UI-W2:925`; nothing
in the UI sets it to false), so the boxes are typed into a picture of the form and copied to the saved keys by
`syncPdfToForm` (`UI-W2:1166-1230`) on save (`UI-W2:1436-1440`). The alternative "form view" (`UI-W2:42-505`) is
never shown. Upload extraction fills the same keys (`us-tax-be/.../microservices/W2FieldMapper.java:22-52`).

### Box 13 checkboxes

`statutoryEmployee` → D-1a-4; `retirementPlan` → IRA deduction coverage (Match); `thirdPartySickPay` → stored only
(Match: no return line). All three are plain checkboxes in the replica (`UI-W2:663-665`).

### Box 14 items

- The 2025 W-2 has a single box 14 "Other" (`fw2.pdf p. 3`). The app's replica draws the 2026 layout: "14a Other"
  (bound to `box14Other[0].label`) and "14b Treasury Tipped Occupation Code(s)" (bound to `box14Other[1].label`,
  `box14Other[2].label`), with **no amount input** (`UI-W2:670-682`); `syncPdfToForm` does not parse an amount out of
  the label (`UI-W2:1207-1212`). Upload extraction does not map box 14 either (`W2FieldMapper.java:22-52`). So a
  box 14 amount cannot reach `box14Amount` (D-w-2-7).
- **RRTA compensation** — the only box 14 item compute uses. Compute reads it from the W-2 key
  `rRTACompensationW2Box14`, which neither the W-2 screen nor extraction writes (D-w-2-1). The Tip-income form has its
  own "RRTA compensation (W-2 box 14)" / "RRTA Medicare Tax withheld (W-2 box 14)" fields per employer
  (`form-tip-income-spouse.component.ts:369-386`) that feed Form 4137 (`TRCS:42660`) and Form 8959 line 23
  (`sumRrtaAmtWithheldFromTipForm`, `TRCS:52250-52266`, used `TRCS:44081-44083`); its pre-fill from W-2 box 14
  (`form-tip-income-taxpayer.component.ts:1050-1073`) needs `box14Amount`, which cannot be entered.
- **Qualified tips / overtime** that an employer may report in box 14 (`i1040gi_ty2025.pdf p. 103, p. 106`) are not read
  from the W-2; the Schedule 1-A forms ask for them. The IRS lets the filer use box 7 or other records, so this is a
  Match.
- Everything else (state disability insurance, union dues, …) is informational.
